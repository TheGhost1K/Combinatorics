# Combinatorics

Библиотека комбинаторных чисел на C#.

## Возможности

- **Базовые:** факториал, сочетания, размещения, перестановки, Паскаль.
- **Классические:** Каталан, Нараян, Моцкин (обычный, 2-цветный, обобщённый).
- **Разбиения:** Стирлинг 1-го и 2-го рода, Белл, Лах, Fubini.
- **Перестановки:** Эйлера (подъёмы/спуски).
- **Пути:** Деланнуа, Шрёдер (большой и малый), Шрёдер–Каталан.
- **Обобщения:** Фусс–Каталан.
- **Рекуррентные:** Фибоначчи, Люка, Пелль, Пелль–Люка.
- **Бернулли:** точные дроби через `BigRational`.
- **Формулы Бине:** в точной арифметике Q(√d) через `QuadraticSurd`.
- **Асимптотики:** базовые и расширенные с оценкой погрешности.
- **Генераторы:** перестановки и сочетания (ленивые).
- **Красивый вывод:** форматирование и печать результатов.

## Быстрый старт

```csharp
using static Combinatorics.Combinatorics;

var fact    = Factorial(20);          // 2432902008176640000
var hands   = Combinations(52, 5);    // 2598960
var catalan = Catalan(10);            // 16796
var fib100  = FibonacciFast(100);     // 354224848179261915075
var b6      = Bernoulli(6);           // 1/42
```
