# Числа Каталана

Одно из самых известных семейств в комбинаторике. Встречается буквально везде.

## Определение

**Формула:** `C_n = C(2n, n) / (n+1) = (2n)! / ((n+1)! · n!)`.

**Рекуррентность:** `C_0 = 1`, `C_{n+1} = Σ_{i=0}^{n} C_i · C_{n−i}`.

**Производящая функция:** `C(x) = (1 − √(1 − 4x)) / (2x)`.

**OEIS:** [A000108](https://oeis.org/A000108).

**Первые значения:** 1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862, 16796, …

## Комбинаторный смысл

`C_n` считает **как минимум** следующее:

1. **Правильные скобочные последовательности** из n пар скобок: для n = 3 — `((()))`, `(()())`, `(())()`, `()(())`, `()()` — всего 5.
2. **Бинарные деревья** с n внутренними узлами.
3. **Пути Дика** из (0,0) в (2n, 0), не поднимающиеся ниже оси.
4. **Триангуляции** выпуклого (n+2)-угольника.
5. **Разбиения** выпуклого (n+2)-угольника на треугольники диагоналями.
6. **Способы умножить** n+1 множителей всевозможными расстановками скобок.

## Примеры кода

```csharp
using static Combinatorics.Combinatorics;

Catalan(0);       // 1
Catalan(5);       // 42
Catalan(10);      // 16796
Catalan(15);      // 9694845
Catalan(20);      // 6564120420
```

## Последовательность

```csharp
var seq = CatalanSequence(11);
// 1, 1, 2, 5, 14, 42, 132, 429, 1430, 4862, 16796
```

**Сложность:** O(n) через рекуррентность `C_{n+1} = C_n · 2(2n+1) / (n+2)`.

## Асимптотика

**Формула:** `C_n ~ 4^n / (n^{3/2} · √π)`.

```csharp
CatalanApprox(100);         // 8.96e56 — базовая, O(1/n)
CatalanApproxExtended(100); // точнее на 4 знака, O(1/n⁴)
```

## Связи

- `Catalan(n) = Narayana(n, k)` суммируется по k: `Σ_k N(n, k) = C_n`.
- `MotzkinTwoColored(n) = Catalan(n+1)`.
- `FussCatalan(n, 1) = Catalan(n)`.
- `SchroederLarge(n) / 2 = SchroederSmall(n)` для n ≥ 1.

## Обобщения

**Числа Нараяны** разбивают `C_n` по числу «внешних» пар скобок:

```csharp
Narayana(6, 3);   // 50
NarayanaRow(6);   // 0, 1, 15, 50, 50, 15, 1
// Сумма = Catalan(6) = 132
```

**Числа Фусса–Каталана** обобщают на (m+1)-арные деревья:

```csharp
FussCatalan(5, 1);   // 42 = Catalan(5)
FussCatalan(5, 2);   // 273 — тернарные деревья
FussCatalan(5, 3);   // 969 — четвертичные
```

## Зачем это нужно

Числа Каталана — самый «универсальный» счётчик в комбинаторике. Если в задаче есть **вложенность** (скобки, деревья, рекурсивные структуры), скорее всего ответ — число Каталана. Это первое семейство, которое стоит проверять при виде «правильной скобочной последовательности» или «бинарного дерева».

## Как это выводится

### Из рекуррентности

Обозначим `C_n` — число правильных скобочных последовательностей длины 2n. Рассмотрим первую пару: она открывается в позиции 1 и закрывается в позиции 2k+2. Внутри неё — правильная последовательность из k пар, снаружи — из n−1−k пар:

```
C_n = Σ_{k=0}^{n−1} C_k · C_{n−1−k},   C_0 = 1
```

### Замкнутая формула

Через **производящую функцию** `C(x) = Σ C_n x^n`:

```
C(x) = 1 + x · C(x)²
```

Решая квадратное уравнение: `C(x) = (1 − √(1 − 4x)) / (2x)`. Разложение в ряд Тейлора даёт замкнутую формулу `C_n = C(2n, n) / (n+1)`.

### Доказательство целочисленности

Менее очевидно, что `C(2n, n) / (n+1)` всегда целое. Это следует из того, что `C_n` — количество объектов (скобочных последовательностей), а их целое число.

## Где встречается

| Задача | Интерпретация |
|---|---|
| Правильные скобочные последовательности | `((()))`, `(()())` и т.д. |
| Бинарные деревья с n узлами | Левое и правое поддеревья — рекурсивно |
| Пути Дика | Пути из (0,0) в (2n, 0), не ниже оси |
| Триангуляции (n+2)-угольника | Диагонали, не пересекающиеся внутри |
| Расстановка скобок в произведении | n+1 множителей, все способы группировки |
| Монотонные пути на решётке | Из (0,0) в (n,n), не выше диагонали |
| Стек-сортировка перестановок | Перестановки 123-avoiding |

## Как это использовать на практике

### Проверка: является ли последовательность скобок правильной

```csharp
// Если всего n пар скобок и последовательность правильная,
// то таких последовательностей C_n.
// Проверка конкретной — через счётчик баланса.
```

### Подсчёт деревьев

Если у вас рекурсивная структура (парсер, AST), где каждый узел имеет ровно 0 или 2 потомка, число возможных деревьев глубины n — число Каталана.

### В алгоритмах на строках

Задача «минимальное число операций для балансировки скобок» связана с числами Каталана. NP-трудные варианты обобщают их.

## Типичные ошибки

**1. Путать `C_n` с `C(2n, n)`.**

`C(2n, n)` — сочетания из `2n` по `n`, например `C(4, 2) = 6`. `C_2 = 2` — это **другое** число (число Каталана с индексом 2). Обозначения похожи, смысл разный.

**2. Считать `Catalan(n)` для n > 100 напрямую через факториалы.**

`C(2n, n)` для больших n — огромное число. Правильно считать через рекуррентность `C_{n+1} = C_n · 2(2n+1)/(n+2)` — так растут промежуточные значения медленнее.

**3. Ожидать, что `Catalan(n)` растёт как `n!`.**

Растёт экспоненциально: `C_n ~ 4^n / (n^{3/2}√π)`. Для `n = 100` это ~`9·10⁵⁶`, а `100! ~ 9·10¹⁵⁷`.

**4. Использовать `Catalan` для путей на прямоугольной решётке.**

Каталан считает пути в **квадрате** (n, n) или на диагонали. Для прямоугольных путей используйте `Delannoy` или `Combinations`.
