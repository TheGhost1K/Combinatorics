# Асимптотики

Приближённые формулы для больших n — O(1) вместо точных мегабайт.

## Зачем нужны

Для `n = 10 000` точное `n!` занимает ~35 000 знаков. Приближение — те же 8 байт `double`. Если нужна оценка (например, для сравнения или выбора алгоритма), приближение в миллионы раз быстрее.

## Базовая и расширенная

| Метод | Погрешность |
|---|---|
| `FactorialStirling` | O(1/n) |
| `FactorialStirlingRefined` | O(1/n³) |
| `FactorialStirlingExtended` | O(1/n⁴) |
| `LogFactorialLanczos` | ~10⁻¹⁵ (машинная) |
| `CatalanApprox` | O(1/n) |
| `CatalanApproxExtended` | O(1/n⁴) |
| `FibonacciApprox` | O(φ⁻²ⁿ) — очень быстро |
| `FibonacciApproxExtended` | машинная для F(n) < 2⁵³ |
| `BellApprox` | O(1/n) |
| `BellApproxExtended` | O(1/n²) |

## Формулы

### Факториал (Стирлинг)

```
n! ≈ √(2πn) · (n/e)^n · (1 + 1/(12n) + 1/(288n²) − 139/(51840n³) − …)
```

```csharp
FactorialStirling(100);            // 9.33e157 — базовая
FactorialStirlingRefined(100);     // + 1/(12n)
FactorialStirlingExtended(100);    // + 3 члена
LogFactorialLanczos(100);          // ln(100!) с машинной точностью
```

### Каталан

```
C_n ≈ 4^n / (n^{3/2} · √π) · (1 − 9/(8n) + 145/(128n²) − …)
```

```csharp
CatalanApprox(100);            // 8.96e56
CatalanApproxExtended(100);    // точнее
```

### Фибоначчи (Бине)

```
F_n = (φ^n − ψ^n) / √5
```

Так как `|ψ| < 1`, второе слагаемое быстро стремится к нулю:

```csharp
FibonacciApprox(50);            // 1.2586e10
FibonacciApproxExtended(50);    // полная формула в double
LucasApprox(50);
LucasApproxExtended(50);
```

### Белл (через функцию Ламберта W)

```
B_n ≈ n^{−1/2} · (n/W(n))^{n+1/2} · exp(n/W(n) − n − 1)
```

```csharp
BellApprox(50);            // 1.86e47
BellApproxExtended(50);    // + поправка 1/(12W(n))
```

### Сочетания

```
C(n, k) ≈ n^n / (k^k · (n−k)^{n−k}) · √(n / (2π · k · (n−k)))
```

```csharp
CombinationsApprox(1000, 500);   // 2.70e299
```

### Деланнуа, Шрёдер, Моцкин

```csharp
DelannoyCentralApprox(100);              // ~1.5e76
DelannoyCentralApproxExtended(100);      // точнее
SchroederLargeApprox(100);
SchroederLargeApproxExtended(100);
MotzkinApprox(100);
```

## Оценка погрешности

```csharp
var exact = Factorial(20);
var approx = FactorialStirling(20);
var err = RelativeError(exact, approx);
// ~0.0004 (0.04%)

var approxExtended = FactorialStirlingExtended(20);
var errExtended = RelativeError(exact, approxExtended);
// ~1e-10
```

**`RelativeError(exact, approx)`** возвращает `|approx − exact| / exact`.

## Специальные функции

### Функция Ламберта W

Решение уравнения `W·e^W = x`. Используется в асимптотике Белла.

```csharp
LambertW(1.0);       // 0.5671432904
LambertW(Math.E);    // 1.0
LambertW(1e15);      // ~26.36
```

**Метод Галлея** — кубическая сходимость, точность ~10⁻¹⁵.

### Гамма Ланцоша

Аппроксимация гамма-функции с точностью ~10⁻¹⁵.

```csharp
GammaLanczos(5.0);     // 24 = 4!
GammaLanczos(0.5);     // √π ≈ 1.7724
GammaLanczos(2.5);     // 3√π/4 ≈ 1.3293

LogGammaLanczos(100);  // ln(99!) ≈ 359.13
```

| n | Stirling | Refined | Extended | Lanczos |
|---|---|---|---|---|
| 10 | 0.8% | 8e-4% | 1e-8% | 1e-14% |
| 20 | 0.4% | 1e-4% | 1e-10% | 1e-15% |
| 50 | 0.2% | 7e-6% | 1e-13% | 1e-15% |
| 100 | 0.1% | 8e-7% | 1e-15% | 1e-15% |

## Зачем это нужно

Для n = 1000 точное значение `n!` — это число из 2568 знаков. Вычислить его можно, но зачем, если нужна только **оценка**? Асимптотика даёт значение за O(1) с погрешностью 10⁻¹⁵ для расширенных формул. Это критично для алгоритмов, где важна скорость, а не последняя цифра.

## Как это выводится

### Формула Стирлинга

Из интегрального представления `n! = ∫₀^∞ t^n e^{−t} dt` (гамма-функция). Метод Лапласа: подынтегральная функция имеет максимум в `t = n`, разложение в окрестности даёт:

```
n! ≈ √(2πn) · (n/e)^n · (1 + 1/(12n) + …)
```

### Формула Каталана

Из `C_n = C(2n, n)/(n+1)` и формулы Стирлинга для сочетаний. Основной член — `4^n/(n^{3/2}√π)`.

### Фибоначчи

Прямо из формулы Бине: `F_n = (φ^n − ψ^n)/√5`. Так как `|ψ| < 1`, второй член мал для больших n:

```
F_n ≈ φ^n / √5
```

Погрешность `O(φ^{−2n})` — убывает экспоненциально.

### Белл

Из экспоненциальной производящей функции `Σ B_n x^n/n! = e^{e^x − 1}`. Метод Лапласа даёт асимптотику через функцию Ламберта W:

```
B_n ≈ n^{−1/2} · (n/W(n))^{n+1/2} · exp(n/W(n) − n − 1)
```

### Гамма Ланцоша

Аппроксимация через рациональную функцию от `x + g`:

```
Γ(z+1) ≈ √(2π) · (z + g + 0.5)^{z+0.5} · e^{−(z+g+0.5)} · A_g(z)
```

где `A_g(z)` — ряд из коэффициентов Ланцоша. При g = 7, n = 9 точность ~10⁻¹⁵.

## Где это использовать

| Сценарий | Что использовать |
|---|---|
| Быстрая оценка для алгоритма | `FactorialStirling` |
| Точные расчёты до 15 знаков | `FactorialStirlingExtended`, `GammaLanczos` |
| Проверка точного значения | `RelativeError` |
| Логарифм для n > 1000 | `LogFactorialLanczos` |
| Оценка роста комбинаторных объектов | Соответствующие `*Approx` |

## Пример: анализ алгоритма

Пусть алгоритм перебирает `n!` вариантов. Сколько операций для n = 20?

```csharp
var exact = Factorial(20);            // 2432902008176640000
var approx = FactorialStirling(20);   // 2.42e18
var err = RelativeError(exact, approx);  // 0.4%

// Для n = 100 — то же самое, но мгновенно
var approx100 = FactorialStirling(100);  // 9.33e157
```

## Точность в деталях

### Факториал

| n | Stirling | Refined | Extended | Lanczos |
|---|---|---|---|---|
| 5 | 1.5% | 0.016% | 2e-7% | 1e-13% |
| 10 | 0.8% | 0.0008% | 1e-8% | 1e-14% |
| 20 | 0.4% | 0.0001% | 1e-10% | 1e-15% |
| 50 | 0.17% | 7e-6% | 1e-13% | 1e-15% |
| 100 | 0.08% | 8e-7% | 1e-15% | 1e-15% |

**Вывод:** для n ≥ 20 расширенная формула даёт практически машинную точность.

### Каталан

| n | Базовая | Расширенная |
|---|---|---|
| 10 | 1% | 1e-6% |
| 50 | 0.2% | 1e-13% |
| 100 | 0.1% | 1e-15% |

### Фибоначчи

Для всех n (кроме очень малых) `FibonacciApprox` даёт погрешность < 10⁻¹⁰. Расширенная — машинная точность.

## Когда асимптотика НЕ работает

- **n маленькое** (< 5): погрешность слишком большая, используйте точное значение.
- **Нужна последняя цифра:** асимптотика даёт `double`, а не точное число.
- **Задача на делимость:** нужны точные значения по модулю. Асимптотика не подходит.
- **Сравнение двух огромных чисел:** `double` переполнится для n > 170. Используйте логарифмы (`LogFactorialLanczos`).

## Типичные ошибки

**1. Ожидать точного значения от асимптотики.**

Все методы `*Approx` возвращают `double` — это всегда **приближение**. Для точных значений используйте сами `Factorial`, `Catalan`, `Bell`, и т.д.

**2. Использовать базовую формулу для n < 20.**

Погрешность 1% и больше. Для таких n лучше считать точно — `BigInteger` справляется мгновенно.

**3. Сравнивать два `double` через `==`.**

Из-за ошибок округления используйте `RelativeError` или сравнение с эпсилоном.

**4. Забыть про переполнение `double`.**

`FactorialStirling(200)` вернёт `Infinity`. Для n > 170 используйте `LogFactorialLanczos` — там результат в логарифмической шкале.

**5. Считать `BellApprox(0)`.**

Формула требует `LambertW(n)` с `n ≥ 1`. Для `n = 0` используйте точное `Bell(0) = 1`.
