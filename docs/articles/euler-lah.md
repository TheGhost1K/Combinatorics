# Числа Эйлера и Лаха

Ещё два семейства, связанных с перестановками и разбиениями.

## Числа Эйлера

**Определение:** `A(n, k)` — число перестановок n элементов ровно с k **подъёмами** (позиций i, где `π_i < π_{i+1}`).

**Формула:** `A(n, k) = Σ_{j=0}^{k+1} (−1)^j · C(n+1, j) · (k+1−j)^n`.

**Рекуррентность:** `A(n, k) = (k+1)·A(n−1, k) + (n−k)·A(n−1, k−1)`.

**Симметрия:** `A(n, k) = A(n, n−1−k)`.

**Сумма по k:** `Σ_k A(n, k) = n!`.

**OEIS:** [A008292](https://oeis.org/A008292).

**Пример:** для n = 4 (24 перестановки):
- 0 подъёмов (убывающие): 1.
- 1 подъём: 11.
- 2 подъёма: 11.
- 3 подъёма (возрастающая): 1.

Строка: 1, 11, 11, 1.

```csharp
Eulerian(5, 2);         // 66
EulerianRow(5);         // 1, 26, 66, 26, 1
// Сумма = 120 = 5!

EulerianDescents(5, 2); // 26 — симметрия с подъёмами
```

## Числа Лаха

**Определение:** `L(n, k) = C(n−1, k−1) · n! / k!` — число разбиений n элементов на k **линейно упорядоченных** подмножеств (списков).

**Связь со Стирлингом:** `L(n, k) = Σ_j |s(n, j)| · S(j, k)`.

**OEIS:** [A105278](https://oeis.org/A105278).

**Пример:** n = 3, k = 2 — сколько способов разбить {a, b, c} на 2 списка?

```csharp
Lah(5, 3);         // 120
LahRow(5);         // 0, 120, 240, 120, 20, 1
```

## Упорядоченные числа Белла (Fubini)

**Определение:** `F(n) = Σ_k L(n, k)` — число всех упорядоченных разбиений.

**OEIS:** [A000670](https://oeis.org/A000670).

**Первые значения:** 1, 1, 3, 13, 75, 541, 4683, 47293, …

```csharp
OrderedBell(0);   // 1
OrderedBell(5);   // 541
OrderedBell(6);   // 4683
```

**Асимптотика:** `F(n) ~ n! / (2 · (ln 2)^{n+1})`.

## Сравнительная таблица

| Числа | Считают | Сумма по k |
|---|---|---|
| Эйлера `A(n, k)` | перестановки с k подъёмами | `n!` |
| Лаха `L(n, k)` | разбиения на k списков | Fubini `F(n)` |
| Стирлинга 2-го `S(n, k)` | разбиения на k подмножеств | Белл `B_n` |
| Стирлинга 1-го `c(n, k)` | перестановки с k циклами | `n!` |
