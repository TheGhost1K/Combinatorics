# Числа Эйлера и Лаха

Ещё два семейства, связанных с перестановками и разбиениями.

## Числа Эйлера

**Определение:** `A(n, k)` — число перестановок n элементов ровно с k **подъёмами** (позиций i, где `π_i < π_{i+1}`).

**Формула:** `A(n, k) = Σ_{j=0}^{k+1} (−1)^j · C(n+1, j) · (k+1−j)^n`.

**Рекуррентность:** `A(n, k) = (k+1)·A(n−1, k) + (n−k)·A(n−1, k−1)`.

**Симметрия:** `A(n, k) = A(n, n−1−k)`.

**Сумма по k:** `Σ_k A(n, k) = n!`.

**OEIS:** [A008292](https://oeis.org/A008292).

**Пример:** для n = 4 (24 перестановки):
- 0 подъёмов (убывающие): 1.
- 1 подъём: 11.
- 2 подъёма: 11.
- 3 подъёма (возрастающая): 1.

Строка: 1, 11, 11, 1.

```csharp
Eulerian(5, 2);         // 66
EulerianRow(5);         // 1, 26, 66, 26, 1
// Сумма = 120 = 5!

EulerianDescents(5, 2); // 26 — симметрия с подъёмами
```

## Числа Лаха

**Определение:** `L(n, k) = C(n−1, k−1) · n! / k!` — число разбиений n элементов на k **линейно упорядоченных** подмножеств (списков).

**Связь со Стирлингом:** `L(n, k) = Σ_j |s(n, j)| · S(j, k)`.

**OEIS:** [A105278](https://oeis.org/A105278).

**Пример:** n = 3, k = 2 — сколько способов разбить {a, b, c} на 2 списка?

```csharp
Lah(5, 3);         // 120
LahRow(5);         // 0, 120, 240, 120, 20, 1
```

## Упорядоченные числа Белла (Fubini)

**Определение:** `F(n) = Σ_k L(n, k)` — число всех упорядоченных разбиений.

**OEIS:** [A000670](https://oeis.org/A000670).

**Первые значения:** 1, 1, 3, 13, 75, 541, 4683, 47293, …

```csharp
OrderedBell(0);   // 1
OrderedBell(5);   // 541
OrderedBell(6);   // 4683
```

**Асимптотика:** `F(n) ~ n! / (2 · (ln 2)^{n+1})`.

## Сравнительная таблица

| Числа | Считают | Сумма по k |
|---|---|---|
| Эйлера `A(n, k)` | перестановки с k подъёмами | `n!` |
| Лаха `L(n, k)` | разбиения на k списков | Fubini `F(n)` |
| Стирлинга 2-го `S(n, k)` | разбиения на k подмножеств | Белл `B_n` |
| Стирлинга 1-го `c(n, k)` | перестановки с k циклами | `n!` |

## Зачем это нужно

Числа Эйлера и Лаха — «спутники» Стирлинга. Эйлера считает перестановки по **подъёмам**, что важно в анализе «пилообразных» последовательностей, сортировке и статистике. Лаха — компромисс между Стирлингом 1-го и 2-го рода: разбиения на **упорядоченные** блоки.

## Как это выводится

### Числа Эйлера

Рассмотрим перестановку `π` длины n. **Подъём** — позиция i, где `π_i < π_{i+1}`. Обозначим `A(n, k)` — число перестановок ровно с k подъёмами.

Возьмём перестановку из n−1 элементов и вставим n. Куда бы мы его ни вставили:

- В конец — число подъёмов не меняется или увеличивается на 1 (в зависимости от последнего элемента).
- В середину — либо создаётся новый подъём, либо сдвигается существующий.

Суммируя по всем позициям, получаем `A(n, k) = (k+1)·A(n−1, k) + (n−k)·A(n−1, k−1)`.

Замкнутая форма получается через **инверсии** и принцип включений-исключений:

```
A(n, k) = Σ_{j=0}^{k+1} (−1)^j · C(n+1, j) · (k+1−j)^n
```

### Числа Лаха

Лах считает разбиения n элементов на k **линейно упорядоченных** блоков. Вывод через связь со Стирлингом:

1. Разбиваем n элементов на k неупорядоченных блоков: `S(n, k)` способов.
2. Внутри каждого блока упорядочиваем элементы: `k!` способов (но лишний раз — упорядоченность учитывается один раз).

Точнее: `L(n, k) = Σ_j |s(n, j)| · S(j, k)`, где `s` — знаковые числа Стирлинга 1-го рода.

Замкнутая формула: `L(n, k) = C(n−1, k−1) · n! / k!`.

### Fubini

`F(n) = Σ_k L(n, k) = Σ_k k! · S(n, k)` — упорядоченные разбиения.

## Где встречается

| Задача | Что использовать |
|---|---|
| Перестановки с k подъёмами | `Eulerian(n, k)` |
| Число сравнений в сортировке | Связано с распределением подъёмов |
| Число спусков в случайной перестановке | `EulerianDescents(n, k)` |
| Разбить n элементов на k списков | `Lah(n, k)` |
| Упорядоченные разбиения | `OrderedBell(n)` |
| Системы с приоритетами (расписание) | `Lah` — блоки различимы |

## Как это использовать на практике

### Анализ сортировок

Пусть массив нужно отсортировать. Число инверсий — одна из ключевых характеристик. Подъёмы — другая. Числа Эйлера дают **распределение числа подъёмов** в случайной перестановке длины n. Это используется в анализе алгоритмов сортировки вставками.

### Комбинаторика перестановок

Задача «сколько перестановок n элементов имеют ровно k возрастающих пар» — `A(n, k)`.

### Системы приоритетов

Задача «расписать n задач по k исполнителям, задачи выполняются в порядке приоритета» — `Lah(n, k)`.

## Связи

- `Σ_k A(n, k) = n!` — сумма по всем подъёмам даёт все перестановки.
- `A(n, k) = A(n, n−1−k)` — симметрия подъёмов и спусков.
- `A(n, 0) = 1` — только убывающая перестановка не имеет подъёмов.
- `A(n, n−1) = 1` — только возрастающая перестановка имеет максимум подъёмов.
- `Σ_k L(n, k) = OrderedBell(n) = Fubini(n)`.

## Типичные ошибки

**1. Считать подъёмы и спуски независимо.**

Между ними есть связь: `подъёмы + спуски = n−1` (по определению, каждая позиция — либо подъём, либо спуск, если нет равных). `A(n, k) = A(n, n−1−k)` — симметрия.

**2. Использовать `Eulerian(n, k)` для больших n без `BigInteger`.**

`A(50, 25)` — огромное число, не помещается в `long`. Только `BigInteger`.

**3. Путать Лаха со Стирлингом.**

- `S(n, k)` — блоки неразличимы, элементы внутри не упорядочены.
- `L(n, k)` — блоки различимы (упорядочены), элементы внутри упорядочены.
- `OrderedBell(n) = Σ L(n, k)` — сумма даёт все упорядоченные разбиения.

**4. Забыть про `A(n, 0) = 1` при n = 0.**

`A(0, 0) = 1` — пустая перестановка не имеет ни подъёмов, ни спусков.
