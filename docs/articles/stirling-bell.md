# Числа Стирлинга и Белла

Семейство чисел, описывающих разбиения множеств и цикловую структуру перестановок.

## Числа Стирлинга первого рода

**Определение:** `c(n, k)` — число перестановок n элементов ровно с k циклами.

**Рекуррентность:** `c(n, k) = c(n−1, k−1) + (n−1)·c(n−1, k)`.

**Сумма по k:** `Σ_k c(n, k) = n!`.

**OEIS:** [A130534](https://oeis.org/A130534).

**Пример:** для n = 3, 6 перестановок:
- 1 цикл: (123), (132) → 2.
- 2 цикла: (1)(23), (12)(3), (13)(2) → 3.
- 3 цикла: (1)(2)(3) → 1.

```csharp
StirlingFirstKind(5, 2);   // 50
StirlingFirstKindRow(5);   // 0, 24, 50, 35, 10, 1
// Сумма = 5! = 120
```

## Знаковые числа Стирлинга первого рода

**Определение:** `s(n, k) = (−1)^(n−k) · |c(n, k)|`.

**Смысл:** коэффициенты падающего факториала `x·(x−1)·…·(x−n+1)`.

```csharp
// x(x−1)(x−2) = x³ − 3x² + 2x
SignedStirlingFirstKind(3, 3);   // 1
SignedStirlingFirstKind(3, 2);   // -3
SignedStirlingFirstKind(3, 1);   // 2
```

**OEIS:** [A048994](https://oeis.org/A048994).

## Числа Стирлинга второго рода

**Определение:** `S(n, k)` — число разбиений множества из n элементов ровно на k непустых подмножеств.

**Рекуррентность:** `S(n, k) = S(n−1, k−1) + k·S(n−1, k)`.

**Формула:** `S(n, k) = (1/k!) · Σ_{j=0}^{k} (−1)^{k−j} · C(k, j) · j^n`.

**OEIS:** [A008277](https://oeis.org/A008277).

**Пример:** для n = 3, k = 2 — разбить {a, b, c} на 2 подмножества:
- {a}, {b, c}
- {b}, {a, c}
- {c}, {a, b}

Всего 3.

```csharp
StirlingSecondKind(5, 2);    // 15
StirlingSecondKind(10, 5);   // 42525
StirlingSecondKindRow(5);    // 0, 1, 15, 25, 10, 1
```

## Числа Белла

**Определение:** `B_n = Σ_k S(n, k)` — число всех разбиений множества из n элементов.

**Рекуррентность:** `B_{n+1} = Σ_{k=0}^{n} C(n, k) · B_k`.

**OEIS:** [A000110](https://oeis.org/A000110).

**Первые значения:** 1, 1, 2, 5, 15, 52, 203, 877, 4140, 21147, 115975, …

```csharp
Bell(0);           // 1
Bell(5);           // 52
Bell(10);          // 115975
BellSequence(11);  // 1, 1, 2, 5, 15, 52, 203, 877, 4140, 21147, 115975
```

**Сложность:** O(n²).

## Асимптотика

**Белла:** через функцию Ламберта W:

```
B_n ≈ n^(−1/2) · (n/W(n))^(n+1/2) · exp(n/W(n) − n − 1)
```

```csharp
BellApprox(50);          // 1.86e47
BellApproxExtended(50);  // точнее, O(1/n²)
```

## Связи

- `Bell(n) = Σ_k StirlingSecondKind(n, k)`.
- `OrderedBell(n) = Σ_k Lah(n, k)` — упорядоченная версия.
- `Bell(n)` — моменты распределения Пуассона.
