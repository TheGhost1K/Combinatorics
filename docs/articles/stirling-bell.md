# Числа Стирлинга и Белла

Семейство чисел, описывающих разбиения множеств и цикловую структуру перестановок.

## Числа Стирлинга первого рода

**Определение:** `c(n, k)` — число перестановок n элементов ровно с k циклами.

**Рекуррентность:** `c(n, k) = c(n−1, k−1) + (n−1)·c(n−1, k)`.

**Сумма по k:** `Σ_k c(n, k) = n!`.

**OEIS:** [A130534](https://oeis.org/A130534).

**Пример:** для n = 3, 6 перестановок:
- 1 цикл: (123), (132) → 2.
- 2 цикла: (1)(23), (12)(3), (13)(2) → 3.
- 3 цикла: (1)(2)(3) → 1.

```csharp
StirlingFirstKind(5, 2);   // 50
StirlingFirstKindRow(5);   // 0, 24, 50, 35, 10, 1
// Сумма = 5! = 120
```

## Знаковые числа Стирлинга первого рода

**Определение:** `s(n, k) = (−1)^(n−k) · |c(n, k)|`.

**Смысл:** коэффициенты падающего факториала `x·(x−1)·…·(x−n+1)`.

```csharp
// x(x−1)(x−2) = x³ − 3x² + 2x
SignedStirlingFirstKind(3, 3);   // 1
SignedStirlingFirstKind(3, 2);   // -3
SignedStirlingFirstKind(3, 1);   // 2
```

**OEIS:** [A048994](https://oeis.org/A048994).

## Числа Стирлинга второго рода

**Определение:** `S(n, k)` — число разбиений множества из n элементов ровно на k непустых подмножеств.

**Рекуррентность:** `S(n, k) = S(n−1, k−1) + k·S(n−1, k)`.

**Формула:** `S(n, k) = (1/k!) · Σ_{j=0}^{k} (−1)^{k−j} · C(k, j) · j^n`.

**OEIS:** [A008277](https://oeis.org/A008277).

**Пример:** для n = 3, k = 2 — разбить {a, b, c} на 2 подмножества:
- {a}, {b, c}
- {b}, {a, c}
- {c}, {a, b}

Всего 3.

```csharp
StirlingSecondKind(5, 2);    // 15
StirlingSecondKind(10, 5);   // 42525
StirlingSecondKindRow(5);    // 0, 1, 15, 25, 10, 1
```

## Числа Белла

**Определение:** `B_n = Σ_k S(n, k)` — число всех разбиений множества из n элементов.

**Рекуррентность:** `B_{n+1} = Σ_{k=0}^{n} C(n, k) · B_k`.

**OEIS:** [A000110](https://oeis.org/A000110).

**Первые значения:** 1, 1, 2, 5, 15, 52, 203, 877, 4140, 21147, 115975, …

```csharp
Bell(0);           // 1
Bell(5);           // 52
Bell(10);          // 115975
BellSequence(11);  // 1, 1, 2, 5, 15, 52, 203, 877, 4140, 21147, 115975
```

**Сложность:** O(n²).

## Асимптотика

**Белла:** через функцию Ламберта W:

```
B_n ≈ n^(−1/2) · (n/W(n))^(n+1/2) · exp(n/W(n) − n − 1)
```

```csharp
BellApprox(50);          // 1.86e47
BellApproxExtended(50);  // точнее, O(1/n²)
```

## Связи

- `Bell(n) = Σ_k StirlingSecondKind(n, k)`.
- `OrderedBell(n) = Σ_k Lah(n, k)` — упорядоченная версия.
- `Bell(n)` — моменты распределения Пуассона.

## Зачем это нужно

Стирлинг и Белл — счётчики **разбиений**. Если задача звучит как «разбить», «сгруппировать», «распределить по категориям» — почти наверняка нужен Стирлинг (с фиксированным числом групп) или Белл (любое число групп). Также они всплывают в анализе цикловой структуры перестановок.

## Как это выводится

### Стирлинг 2-го рода

Рассмотрим разбиение множества `{1, …, n}` на k непустых подмножеств. Возьмём элемент n:

- Он образует одноэлементный блок → оставшиеся n−1 элементов нужно разбить на k−1 блок → `S(n−1, k−1)`.
- Он входит в один из k блоков → сначала разбиваем n−1 элементов на k блоков (`S(n−1, k)` способов), затем помещаем n в один из k блоков.

Итого: `S(n, k) = S(n−1, k−1) + k · S(n−1, k)`.

### Стирлинг 1-го рода

Аналогично, но с циклами. Если в перестановке n элементов ровно k циклов:

- n образует свой цикл (фиксированная точка) → `c(n−1, k−1)`.
- n вставляется в один из циклов перестановки из n−1 элементов. Есть n−1 способов вставить n в существующий цикл (перед каждым из n−1 элементов).

Итого: `c(n, k) = c(n−1, k−1) + (n−1) · c(n−1, k)`.

### Числа Белла

По определению `B_n = Σ_k S(n, k)` — суммируем по всем возможным размерам разбиений. Рекуррентность получается из формулы:

```
B_{n+1} = Σ_{k=0}^{n} C(n, k) · B_k
```

Выбираем место для нового элемента n+1: он может образовать блок с любым подмножеством из n элементов размера k, и остальные n−k элементов разбиваются свободно.

### Знаковые числа Стирлинга 1-го рода

Из производящей функции падающего факториала:

```
x·(x−1)·…·(x−n+1) = Σ_k s(n, k) · x^k
```

Коэффициенты — `s(n, k)` — знаковые числа Стирлинга 1-го рода.

## Где встречается

| Задача | Что использовать |
|---|---|
| Разбить n человек на k групп | `StirlingSecondKind(n, k)` |
| Разбить n человек на группы (любое число) | `Bell(n)` |
| Распределить n шаров по k неразличимым ящикам (без пустых) | `StirlingSecondKind(n, k)` |
| Перестановки n элементов с k циклами | `StirlingFirstKind(n, k)` |
| Ожидаемое число циклов в случайной перестановке | `H_n ≈ ln(n)` — сумма `c(n, k)/n!` по k |
| Разбить множество с учётом порядка блоков | `OrderedBell(n)` |
| Упорядоченное разбиение на k списков | `Lah(n, k)` |

## Как это использовать на практике

### Кластеризация

Задача «разбить n объектов на k кластеров» — по сути `S(n, k)`. Хотя на практике кластеризация решается алгоритмами (k-means), `S(n, k)` — теоретическая верхняя граница числа возможных разбиений.

### Анализ сложности алгоритмов сортировки

Число сравнений в сортировке зависит от цикловой структуры. `Σ_k c(n, k) = n!` — все перестановки. Распределение по числу циклов — нормальное с центром ~`ln(n)`.

### Распределение случайных отображений

Функции `{1, …, n} → {1, …, n}` классифицируются по размеру образа. Число функций с образом размера k — `C(n, k) · S(m, k) · k!` (после m итераций).

## Типичные ошибки

**1. Путать Стирлинг 1-го и 2-го рода.**

- **1-го рода:** перестановки с k циклами.
- **2-го рода:** разбиения на k непустых подмножеств.

Формулы похожи (рекуррентности), но смысл разный.

**2. Забыть про k = 0.**

- `S(n, 0) = 0` для n ≥ 1 (нельзя разбить непустое множество на 0 частей).
- `S(0, 0) = 1` (пустое множество разбивается на 0 частей одним способом).

**3. Считать `Bell(n)` через перебор всех разбиений.**

`B_20 = 51 724 158 235 372`. Прямой перебор невозможен. Используйте треугольник Белла за O(n²).

**4. Считать `Bell(n)` для больших n как `int` или `long`.**

`B_20` уже не помещается в `long` (максимум 2⁶³ ≈ 9.2·10¹⁸). Нужен `BigInteger`.

**5. Думать, что порядок блоков важен.**

В `S(n, k)` блоки **неразличимы**: `{1, 2}, {3}` = `{3}, {1, 2}`. Если порядок важен — используйте `OrderedBell` или `Lah`.
