# Формулы Бине в точной арифметике

Точное вычисление рекуррентных последовательностей через квадратичные иррациональности.

## Идея

Числа вида `a + b·√d` образуют **квадратичное поле** `Q(√d)`. В нём определены сложение, умножение, деление — и формулы Бине становятся точными.

Например, `φ = (1+√5)/2 ∈ Q(√5)`, и `F_n = (φ^n − ψ^n)/√5` — **точное** равенство в этом поле, а не приближённое.

## QuadraticSurd

Класс `QuadraticSurd` представляет числа `(a + b·√d)/c`, где `a, b, c, d ∈ ℤ`, `c > 0`, `d > 0`.

Хранится в нормализованной форме: `gcd(a, b, c) = 1`, знак перенесён в `a` и `b`.

### Создание

```csharp
// φ = (1 + √5)/2
var phi = new QuadraticSurd(1, 1, 2, 5);

// Из целого: 5 + 0·√d
var five = QuadraticSurd.FromInteger(5, 5);

// √d
var sqrt5 = QuadraticSurd.Sqrt(5);

// Предопределённые константы
var phi = Phi;                  // (1 + √5)/2
var psi = Psi;                  // (1 − √5)/2
var onePlusSqrt2 = OnePlusSqrt2; // 1 + √2
```

### Арифметика

```csharp
var x = new QuadraticSurd(1, 1, 1, 2);   // 1 + √2
var y = new QuadraticSurd(1, -1, 1, 2);  // 1 − √2

x + y;   // 2
x - y;   // 2√2
x * y;   // -1 (норма)
x / y;   // -3 − 2√2

-x;      // -1 − √2
```

### Возведение в степень

`QuadraticSurd.Pow(x, n)` — быстрое возведение за O(log n).

```csharp
QuadraticSurd.Pow(phi, 2);   // (3 + √5)/2 = φ + 1
QuadraticSurd.Pow(phi, 10);  // точное значение
QuadraticSurd.Pow(phi, -1);  // φ − 1 = 1/φ
```

### Норма и сопряжение

```csharp
var x = new QuadraticSurd(1, 1, 1, 2);
x.Conjugate;   // 1 − √2
x.Norm;        // -1
```

## Формулы Бине

### Фибоначчи и Люка

```csharp
FibonacciBinet(0);    // 0
FibonacciBinet(50);   // 12586269025
FibonacciBinet(100);  // 354224848179261915075
FibonacciBinet(500);  // точное значение

LucasBinet(0);    // 2
LucasBinet(10);   // 123
LucasBinet(50);   // 28143753123
```

### Пелль и Пелль–Люка

```csharp
PellBinet(0);         // 0
PellBinet(10);        // 2378
PellBinet(50);        // точное

PellLucasBinet(10);   // 6726
PellLucasBinet(50);   // точное
```

## Сравнение методов

| Метод | Сложность | Скорость (n = 1000) |
|---|---|---|
| `Fibonacci(n)` — итеративно | O(n) | 320 μs |
| `FibonacciFast(n)` — fast doubling | O(log n) | 8 μs |
| `FibonacciBinet(n)` — Q(√5) | O(log n) с большей константой | 145 μs |

**Вывод:** для продакшена используйте `FibonacciFast` (работает только с `BigInteger`, в ~18 раз быстрее).

**Формулы Бине** в `QuadraticSurd` — для **учебных целей и теоретических выкладок**: они показывают алгебраическую структуру, лежащую в основе последовательностей.

## Тождества в Q(√5)

```csharp
// φ² = φ + 1
var phi2 = QuadraticSurd.Pow(phi, 2);
var check = phi2 - phi - QuadraticSurd.FromInteger(1, 5);
// check.A = 0, check.B = 0

// φ·ψ = −1
var product = Phi * Psi;   // -1
```

## Тождества в Q(√2)

```csharp
// (1 + √2)(1 − √2) = −1
var product = OnePlusSqrt2 * OneMinusSqrt2;

// (1 + √2)¹⁰ = 3363 + 2378√2
var p10 = QuadraticSurd.Pow(OnePlusSqrt2, 10);
// p10.A = 3363, p10.B = 2378
```

## Вывод в консоль

```csharp
Console.WriteLine(Phi);              // (1 + √5)/2
Console.WriteLine(Psi);              // (1 - √5)/2
Console.WriteLine(Sqrt5);            // √5
Console.WriteLine(QuadraticSurd.FromInteger(5, 5)); // 5
Console.WriteLine(new QuadraticSurd(2, 3, 1, 7));   // (2 + 3√7)
```

## Зачем это нужно

Формулы Бине в точной арифметике — это **алгебраическая основа** всех рекуррентных последовательностей. Изучая их, вы видите, что все числа Фибоначчи, Люка, Пелля живут в квадратичных полях `Q(√5)` и `Q(√2)`. Это даёт единый взгляд на семейства и открывает путь к обобщениям (последовательности Люка, обобщённые Фибоначчи, и т.д.).

## Как это выводится

### Квадратичное поле Q(√d)

Множество `{a + b√d : a, b ∈ Q}` с операциями:

- **Сложение:** покомпонентно.
- **Умножение:** `(a₁ + b₁√d)(a₂ + b₂√d) = (a₁a₂ + b₁b₂d) + (a₁b₂ + a₂b₁)√d`.
- **Сопряжение:** `conj(a + b√d) = a − b√d`.
- **Норма:** `N(x) = x · conj(x) = a² − d b²`.
- **Обратный:** `1/x = conj(x) / N(x)`.

Поле получается, потому что для каждого `x` есть обратный (если `N(x) ≠ 0`).

### Формула Бине

Характеристическое уравнение `x² = x + 1` не имеет рациональных корней, но имеет корни `φ = (1+√5)/2` и `ψ = (1−√5)/2` в `Q(√5)`.

Общее решение рекуррентности: `F_n = A·φ^n + B·ψ^n`. Из начальных условий `F_0 = 0`, `F_1 = 1` находим `A = 1/√5`, `B = −1/√5`.

**Точное равенство:** `F_n = (φ^n − ψ^n) / √5` в поле `Q(√5)`. Результат лежит в `Z` (вложенном в поле как `a + 0·√5`).

### Аналогично для Пелля

Характеристическое уравнение `x² = 2x + 1`, корни `1 ± √2` в `Q(√2)`. Формула: `P_n = ((1+√2)^n − (1−√2)^n) / (2√2)`.

## Почему это важно

### Единый взгляд

Все классические рекуррентные последовательности (`F_n`, `L_n`, `P_n`, `Q_n`) — это **следы и нормы** степеней в квадратичных полях. Это классический результат теории алгебраических чисел.

### Точная арифметика вместо приближённой

Вместо `double` (с потерей точности) мы работаем с точными рациональными и целыми числами. Все тождества (Кассини, Люка, удвоение) выполняются **точно**.

### Обобщения

Обобщая на `Q(√d)` для любого `d`, получаем «последовательности Люка» с произвольными параметрами. Это используется в криптографии (RSA с последовательностями Люка, Lucas-Lehmer test для простоты Мерсенна).

## Где встречается

| Задача | Что использовать |
|---|---|
| Точное вычисление F(n) по формуле | `FibonacciBinet(n)` |
| Проверка тождеств | Операции в `QuadraticSurd` |
| Тесты на простоту | Lucas-Lehmer |
| Учебные выкладки | `Phi`, `Psi`, `Sqrt5` |
| Криптография | Последовательности Люка |

## Практические примеры

### Тождества в Q(√5)

```csharp
// φ² = φ + 1
var phi = Phi;
var phi2 = QuadraticSurd.Pow(phi, 2);
var check = phi2 - phi - QuadraticSurd.FromInteger(1, 5);
// check == 0

// φ·ψ = −1
var product = Phi * Psi;   // -1
```

### Пелль в Q(√2)

```csharp
// (1+√2)^10 = 3363 + 2378√2
var p10 = QuadraticSurd.Pow(OnePlusSqrt2, 10);
// p10.A = 3363, p10.B = 2378
// P_10 = 2378, Q_10 = 6726 — оба соответствуют
```

### Проверка арифметики

```csharp
// (1+√2)·(1−√2) = 1 − 2 = −1
var product = OnePlusSqrt2 * OneMinusSqrt2;
Console.WriteLine(product);   // "-1"
```

## Сравнение с fast doubling

Для **продакшена** используйте fast doubling — он работает в `Z`, а не в `Q(√d)`, и в 18 раз быстрее.

Для **учебных целей** формула Бине нагляднее: она показывает алгебраическую структуру, лежащую в основе рекуррентности.

## Типичные ошибки

**1. Думать, что `φ = 1.618…`, а не `(1+√5)/2`.**

`φ` — точное алгебраическое число. `1.618` — приближение. В `QuadraticSurd` мы храним точное значение.

**2. Пытаться вычислить `FibonacciBinet(1_000_000)`.**

Формула Бине для очень больших n работает медленнее, чем fast doubling. При n > 10 000 используйте `FibonacciFast`.

**3. Ожидать, что `FibonacciBinet` быстрее `FibonacciFast`.**

Нет. `QuadraticSurd` на каждом шаге вызывает `gcd` для нормализации, что делает его медленнее. Быстрое удвоение работает только с `BigInteger`.

**4. Забыть, что операции возможны только для одинаковых `d`.**

`QuadraticSurd.Sqrt(5) + QuadraticSurd.Sqrt(7)` бросит исключение — разные поля. Для сложения нужно одно и то же `d`.

**5. Путать `A`, `B`, `C`, `D` в структуре.**

`QuadraticSurd(a, b, c, d)` — это `(a + b·√d) / c`, а не `a + b·√c + d`. Порядок аргументов: `a`, `b`, `c`, `d`.
