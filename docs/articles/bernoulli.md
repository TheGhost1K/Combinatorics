# Числа Бернулли

Рациональные числа, играющие ключевую роль в анализе и теории чисел.

## Определение

Через производящую функцию:

```
x / (e^x − 1) = Σ_{n=0}^∞ B_n · x^n / n!
```

**Рекуррентность:** `Σ_{k=0}^{n} C(n+1, k) · B_k = 0` для n ≥ 1, `B_0 = 1`.

**Первые значения:**

| n | B_n |
|---|---|
| 0 | 1 |
| 1 | −1/2 |
| 2 | 1/6 |
| 3 | 0 |
| 4 | −1/30 |
| 5 | 0 |
| 6 | 1/42 |
| 7 | 0 |
| 8 | −1/30 |
| 9 | 0 |
| 10 | 5/66 |
| 11 | 0 |
| 12 | −691/2730 |

**Свойства:**
- Все `B_{2k+1} = 0` при k ≥ 1.
- Знаки чередуются: `B_2 > 0`, `B_4 < 0`, `B_6 > 0`, …
- `|B_{2n}|` растёт сверхэкспоненциально.

**OEIS (числители):** [A027641](https://oeis.org/A027641).
**OEIS (знаменатели):** [A027642](https://oeis.org/A027642).

## Примеры кода

```csharp
using static Combinatorics.Combinatorics;

Bernoulli(0);    // 1
Bernoulli(1);    // -1/2
Bernoulli(2);    // 1/6
Bernoulli(3);    // 0
Bernoulli(4);    // -1/30
Bernoulli(6);    // 1/42
Bernoulli(12);   // -691/2730

BernoulliSequence(10);
// 1, -1/2, 1/6, 0, -1/30, 0, 1/42, 0, -1/30, 0
```

**Возвращаемый тип:** `BigRational` — точная дробь без потери точности.

## Форматирование

```csharp
using static Combinatorics.CombinatoricsFormatter;

var b6 = Bernoulli(6);
Console.WriteLine(b6);                    // 1/42
Console.WriteLine(b6.ToDecimalString());  // 0.023810

PrintRational("B(6)", b6, RationalMode.Both);
// B(6) = 1/42 (≈ 0.023810)
```

## Применения

### Формула Фаульхабера — суммы степеней

`Σ_{k=1}^{n} k^m = (1/(m+1)) · Σ_{j=0}^{m} C(m+1, j) · B_j · n^{m+1−j}`.

Например, сумма квадратов: `Σ k² = n(n+1)(2n+1)/6`.

### Дзета-функция Римана при чётных аргументах

```
ζ(2n) = (−1)^{n+1} · B_{2n} · (2π)^{2n} / (2 · (2n)!)
```

Примеры:
- `ζ(2) = π²/6`.
- `ζ(4) = π⁴/90`.
- `ζ(6) = π⁶/945`.

### Разложение Тодда

Классы Тодда в топологии выражаются через числа Бернулли.

## Сложность

`BernoulliSequence(count)` — O(count²) с точной арифметикой `BigRational`.

## Зачем это нужно

Числа Бернулли — «мост» между дискретной комбинаторикой и непрерывным анализом. Они возникают в формулах сумм степеней (Фаульхабер), в разложении тригонометрических функций, в дзета-функции Римана. Их дробная природа делает их незаменимыми в точных вычислениях.

## Как это выводится

### Через производящую функцию

Определим `B_n` как коэффициенты разложения:

```
x / (e^x − 1) = Σ_{n=0}^∞ B_n · x^n / n!
```

Функция `x / (e^x − 1)` аналитична в окрестности нуля. Её коэффициенты Тейлора — числа Бернулли.

### Через рекуррентность

Полагая `x = 0` в разложении и используя свойства экспоненты, получаем:

```
Σ_{k=0}^{n} C(n+1, k) · B_k = 0   для n ≥ 1,   B_0 = 1
```

Это линейная система, решаемая последовательно: `B_0 = 1`, потом `B_1`, потом `B_2`, и т.д.

### Почему нечётные нули

`x / (e^x − 1) + x/2 = (x/2) · coth(x/2)` — чётная функция. Значит, все коэффициенты при нечётных степенях (кроме `x^1`) равны нулю. Отсюда `B_{2k+1} = 0` для k ≥ 1.

## Где встречается

| Задача | Формула |
|---|---|
| Сумма первых n квадратов | `n(n+1)(2n+1)/6 = (1/3)·n³ + (1/2)·n² + (1/6)·n` — коэффициенты через `B_1, B_2, B_3` |
| Сумма первых n кубов | `(n(n+1)/2)²` |
| Сумма первых n m-х степеней | Формула Фаульхабера |
| `ζ(2) = π²/6` | `B_2 = 1/6` |
| `ζ(4) = π⁴/90` | `B_4 = −1/30` |
| `ζ(6) = π⁶/945` | `B_6 = 1/42` |
| Число классов Тодда | В топологии многообразий |

## Как это использовать на практике

### Формула Фаульхабера

Сумма `Σ_{k=1}^{n} k^m` выражается через `B_j`:

```
Σ k^m = (1/(m+1)) · Σ_{j=0}^{m} C(m+1, j) · B_j · n^{m+1−j}
```

Для m = 2: `(1/3)·(B_0·n³ + 3·B_1·n² + 3·B_2·n) = n³/3 + n²/2 + n/6`. Проверьте: `1 + 4 + 9 = 14 = 27/3 + 9/2 + 3/6`. Работает.

### Дзета-функция Римана

Для чётных n:

```
ζ(2n) = (−1)^{n+1} · B_{2n} · (2π)^{2n} / (2 · (2n)!)
```

Отсюда все «красивые» значения: `ζ(2) = π²/6`, `ζ(4) = π⁴/90`, `ζ(6) = π⁶/945`.

### Асимптотика больших B_n

`|B_{2n}| ~ 2 · (2n)! / (2π)^{2n}` — растут факториально, поэтому в приложениях обычно работают с `B_n / n!`.

## Свойства

- **Чётные индексы:** `B_2 = 1/6`, `B_4 = −1/30`, `B_6 = 1/42`, `B_8 = −1/30`, `B_10 = 5/66`, `B_12 = −691/2730`.
- **Нечётные:** `B_1 = −1/2`, `B_{2k+1} = 0` для k ≥ 1.
- **Знаки:** чередуются с ростом индекса.
- **Числители:** OEIS [A027641](https://oeis.org/A027641). Знаменатели: [A027642](https://oeis.org/A027642).
- **Теорема фон Штаудта–Клаузена:** знаменатель `B_{2n}` — произведение простых p, для которых `(p−1) | 2n`.

## Типичные ошибки

**1. Использовать соглашение `B_1 = +1/2`.**

Есть два соглашения: `B_1 = −1/2` (современное) и `B_1 = +1/2` (старое). Мы используем **`B_1 = −1/2`** — это стандарт для производящей функции `x/(e^x − 1)`.

**2. Считать `B_n` как `double`.**

Числа Бернулли — **рациональные**, а не целые. Для точности используйте `BigRational`.

**3. Ожидать, что `B_{2k+1} ≠ 0`.**

Все нечётные `B_{2k+1} = 0` для k ≥ 1. Единственные ненулевые нечётные — `B_1 = −1/2`.

**4. Пытаться вычислить `B_n` для n > 100 без оптимизации.**

Рекуррентность O(n²) с точной арифметикой. Для больших n — медленно, но точно. Для n > 1000 используйте асимптотику: `|B_{2n}| ≈ 2(2n)!/(2π)^{2n}`.

**5. Путать с числами Эйлера.**

Числа **Эйлера** (не путать с **числами Эйлера I и II рода**) — это счётчики перестановок по подъёмам. Числа **Бернулли** — рациональные коэффициенты рядов. Разные семейства.
