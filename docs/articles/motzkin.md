# Числа Моцкина

Обобщение чисел Каталана на пути с горизонтальными шагами.

## Определение

**Смысл:** число путей на решётке из (0,0) в (n,0) с шагами (1,0), (1,1), (1,−1), не опускающихся ниже оси.

**Формула:** `M_n = Σ_{k=0}^{⌊n/2⌋} C(n, 2k) · C_k`, где `C_k` — числа Каталана.

**Рекуррентность:** `M_0 = 1`, `M_{n+1} = M_n + Σ_{i=0}^{n-1} M_i · M_{n-1-i}`.

**OEIS:** [A001006](https://oeis.org/A001006).

**Первые значения:** 1, 1, 2, 4, 9, 21, 51, 127, 323, 835, 2188, …

```csharp
Motzkin(0);              // 1
Motzkin(10);             // 2188
MotzkinSequence(11);     // 1, 1, 2, 4, 9, 21, 51, 127, 323, 835, 2188
```

**Асимптотика:** `M_n ~ 3^{n+3/2} / (2·√π·n^{3/2})`.

```csharp
MotzkinApprox(100);   // ~8.5e47
```

## Two-colored числа Моцкина

**Смысл:** Моцкин-пути с **двумя** цветами горизонтального шага.

**Рекуррентность:** `M_0 = 1`, `M_{n+1} = 2·M_n + Σ M_i · M_{n-1-i}`.

**Интересный факт:** `M_n^(2) = C_{n+1}` — половина… нет, **равно** числу Каталана следующего порядка!

**OEIS:** [A006531](https://oeis.org/A006531).

```csharp
MotzkinTwoColored(0);   // 1 = Catalan(1)
MotzkinTwoColored(5);   // 132 = Catalan(6)
MotzkinTwoColored(8);   // 4862 = Catalan(9)
```

## Обобщённые числа Моцкина

**Определение:** `M_n^(m)` — Моцкин-пути с **m** цветами горизонтального шага.

**Формула:** `M_n^(m) = Σ_{k=0}^{⌊n/2⌋} C(n, 2k) · C_k · m^{n−2k}`.

**Рекуррентность:** `M_{n+1}^(m) = m·M_n^(m) + Σ M_i^(m) · M_{n-1-i}^(m)`.

**Частные случаи:**
- m = 1: обычные Моцкин.
- m = 2: `C_{n+1}`.
- m = 3: [A002212](https://oeis.org/A002212).

```csharp
MotzkinGeneralized(5, 1);   // 21 = Motzkin(5)
MotzkinGeneralized(5, 2);   // 132 = MotzkinTwoColored(5)
MotzkinGeneralized(5, 3);   // 543

MotzkinGeneralizedSequence(8, 3);
// 1, 3, 10, 36, 137, 543, 2219, 9285
```

**Двойная проверка:** через сумму `MotzkinGeneralizedBySum(n, m)` — результат совпадает с рекуррентным.

## Зачем это нужно

Числа Моцкина — это «Каталан с горизонтальными шагами». Они появляются всякий раз, когда в задаче есть **три варианта действия** вместо двух. Это делает их полезными при анализе алгоритмов, где на каждом шаге возможен выбор из нескольких равноправных вариантов.

## Как это выводится

### Обычные Моцкин

Пути на решётке из (0,0) в (n, 0) с шагами:
- `→` (1, 0) — горизонт,
- `↗` (1, 1) — вверх,
- `↘` (1, −1) — вниз,

не опускаясь ниже оси y = 0.

**Декомпозиция:** рассмотрим первый шаг:
- Если `→`, остаётся путь из оставшихся n−1 шагов — `M_{n−1}` вариантов.
- Если `↗`, то парный `↘` вернёт нас на ось через k шагов. Внутри — путь из k шагов, снаружи — n−1−k.

Итого: `M_{n+1} = M_n + Σ_{i=0}^{n−1} M_i · M_{n−1−i}`.

### Через Каталана

Разобьём путь по числу пар `↗ ↔`. Пусть всего k пар. Тогда:
- Позиции для 2k диагональных шагов: `C(n, 2k)`.
- Внутри диагональных шагов — правильная скобочная последовательность из k пар: `C_k` способов.
- Оставшиеся `n − 2k` — горизонтальные шаги: 1 способ (все одинаковы).

Итого: `M_n = Σ_{k=0}^{⌊n/2⌋} C(n, 2k) · C_k`.

### Обобщённые Моцкин с m цветами

Если горизонтальный шаг может быть m цветов, каждая формула умножается на `m^(число горизонтальных шагов)`:

```
M_n^(m) = Σ_k C(n, 2k) · C_k · m^{n−2k}
```

## Где встречается

| Задача | Что использовать |
|---|---|
| Пути без спуска ниже оси с шагами →, ↗, ↘ | `Motzkin(n)` |
| Правильные скобки с «пустыми» парами | `Motzkin(n)` |
| Одноуровневые небинарные деревья | `Motzkin(n)` |
| Пути с двумя типами горизонтальных шагов | `MotzkinTwoColored(n)` |
| Пути с m типами горизонтальных шагов | `MotzkinGeneralized(n, m)` |

## Как это использовать на практике

### Анализ путей в графах

Задача «найти все монотонные пути из A в B, не выходящие за границы» часто сводится к Моцкину, если есть три типа рёбер.

### Языки с тремя типами скобок

Если в языке три типа скобок (например, `()`, `[]`, `{}`), и каждый «уровень» может быть пустым, число правильных выражений длины n — вариант Моцкина.

### Генетика

Моцкин появляется в моделях РНК-фолдинга, где рассматриваются три типа связей.

## Связи с другими числами

| Семейство | Отношение к Моцкину |
|---|---|
| Каталан | `M_n^(2) = C_{n+1}` — двухцветный Моцкин = Каталан со сдвигом |
| Риордан | `M_n^(0)` (без горизонталей) — осциллирующие числа |
| Шрёдер | `Motzkin ≤ Schroeder` по росту |
| Catalan | `M_n ≤ C_n` |

## Типичные ошибки

**1. Путать с Каталаном.**

Каталан — **только** парные шаги `↗ ↔`. Моцкин — плюс горизонтальные шаги. `M_n ≤ C_n` для n ≥ 1.

**2. Ожидать, что `MotzkinTwoColored(n) = 2·Motzkin(n)`.**

Нет: `MotzkinTwoColored(n) = C_{n+1}` — совсем другая последовательность. Удвоение цветов радикально меняет ответ.

**3. Путать `MotzkinGeneralized(n, m)` с `Motzkin(n)`.**

При `m = 1` — совпадают. При `m ≥ 2` — разные.

**4. Считать обобщённый Моцкин только по рекуррентности для больших n.**

Для `n > 1000` рекуррентность O(n²) может быть медленной. Используйте `MotzkinGeneralizedBySum` (закрытая формула) — иногда быстрее, но с большим числом умножений `BigInteger`.
