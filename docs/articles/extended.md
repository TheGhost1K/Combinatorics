# Расширенные семейства

Дополнительные комбинаторные числа и приёмы, дополняющие основную библиотеку.

## Что входит

- **Деланнуа (оптимизированный)** — быстрое вычисление для больших m, n.
- **Числа Дженокки** — родственны числам Бернулли.
- **Формула включений-исключений** — фундаментальный счётный приём.

## Зачем это нужно

Основная библиотека покрывает **классические** семейства (Каталан, Стирлинг, Белл, Моцкин). Расширения добавляют:

- **Оптимизацию** там, где основная реализация становится медленной (Деланнуа).
- **Родственную последовательность**, естественно вписывающуюся в общую картину (Дженокки, родственные Бернулли).
- **Универсальный приём**, часто встречающийся в задачах (включения-исключения).

## Как это выводится

### DelannoyFast

Обычная формула: `D(m, n) = Σ_k C(m, k) · C(n, k) · 2^k` — O(min(m, n)) вызовов `Combinations`, каждый O(k). Итого O(min(m, n)²).

Альтернативная формула: `D(m, n) = Σ_{k=0}^{m} C(m, k) · C(n+k, m)`, где m = min(m, n).

Обе дают одинаковый результат, но альтернативная короче при большом разбросе m и n, потому что суммирование идёт по меньшему измерению, а внутри — более простые вызовы `Combinations(n+k, m)` с фиксированным верхним индексом m.

Для `m·n ≤ 2500` обычная формула быстрее (меньше вызовов), поэтому мы делегируем ей.

### Числа Дженокки

**Производящая функция:** `2x / (e^x + 1) = Σ G_n · x^n / n!`.

**Связь с Бернулли:** сравнивая с `x/(e^x − 1) = Σ B_n · x^n / n!`, получаем:

```
2x/(e^x + 1) = 2x/(e^x − 1) − 4x/(e^{2x} − 1)
```

Отсюда `G_n = 2(1 − 2^n) · B_n`.

**Свойства:**
- `G_0 = 0`, `G_1 = 1`.
- Все `G_{2k+1} = 0` для k ≥ 1.
- Знаки чередуются: `G_2 = −1`, `G_4 = 1`, `G_6 = −3`, `G_8 = 17`.

### Формула включений-исключений

Для конечных множеств A₁, …, Aₙ:

```
|A₁ ∪ … ∪ Aₙ| = Σ|Aᵢ| − Σ|Aᵢ ∩ Aⱼ| + Σ|Aᵢ ∩ Aⱼ ∩ A_k| − …
```

Общая форма:

```
|∪ Aᵢ| = Σ_{∅≠S⊆{1..n}} (−1)^{|S|+1} · |∩_{i∈S} Aᵢ|
```

**Сложность:** O(2ⁿ) по числу подмножеств.

## Где встречается

| Задача | Что использовать |
|---|---|
| Большие пути на решётке | `DelannoyFast` |
| Числа Дженокки в анализе | `Genocchi` |
| Подсчёт «хотя бы одного» события | `InclusionExclusion` |

## Примеры кода

### DelannoyFast

```csharp
using static Combinatorics.Combinatorics;

DelannoyFast(3, 3);         // 63
DelannoyFast(50, 50);       // быстро
DelannoyFast(500, 500);     // всё ещё быстро
```

### Числа Дженокки

```csharp
Genocchi(0);   // 0
Genocchi(2);   // -1
Genocchi(4);   // 1
Genocchi(6);   // -3
Genocchi(8);   // 17

GenocchiSequence(10);
// 0, 1, -1, 0, 1, 0, -3, 0, 17, 0
```

### Включения-исключения

```csharp
var sizes = new[] { 10, 15, 20 };
var union = InclusionExclusion(sizes, idx => idx.Length switch
{
    1 => sizes[idx[0]],
    2 => idx switch
    {
        [0, 1] => 5,
        [0, 2] => 4,
        [1, 2] => 3,
        _ => 0
    },
    3 => 1,
    _ => 0
});
// union = 34
```

## Типичные ошибки

**1. Считать Дженокки как `double`.**

`G_n` целые, но вычисление через `B_n` (рациональное) требует `BigRational`. Не используйте `double` — потеряете точность.

**2. Ожидать, что `Genocchi(n)` быстро для больших n.**

Каждый вызов `Genocchi(n)` строит всю последовательность `Bernoulli` до n. Для серии используйте `GenocchiSequence(count)` — строит один раз.

**3. Путать `DelannoyFast` с `Delannoy`.**

`DelannoyFast` — не новый алгоритм, а **оптимизация** через альтернативную формулу. Результат идентичен.

**4. Использовать `InclusionExclusion` для n > 25.**

Сложность O(2ⁿ). Для n = 30 это 10⁹ подмножеств — минуты. Для больших задач — другие методы (DP по маскам при n ≤ 20, аналитические формулы).
