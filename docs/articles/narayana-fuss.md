# Числа Нараяны и Фусса–Каталана

Два обобщения чисел Каталана.

## Числа Нараяны

**Определение:** `N(n, k) = (1/n) · C(n, k) · C(n, k−1)`.

**Смысл:** правильные скобочные последовательности из n пар ровно с k «внешними» (верхними) парами. Эквивалентно — пути Дика длины 2n ровно с k пиками.

**Сумма по k:** `Σ_{k=1}^{n} N(n, k) = C_n` (число Каталана).

**Симметрия:** `N(n, k) = N(n, n+1−k)`.

**OEIS:** [A001263](https://oeis.org/A001263).

**Треугольник:**

| n\k | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 1 | 1 | | | | |
| 2 | 1 | 1 | | | |
| 3 | 1 | 3 | 1 | | |
| 4 | 1 | 6 | 6 | 1 | |
| 5 | 1 | 10 | 20 | 10 | 1 |

```csharp
Narayana(4, 2);   // 6
Narayana(6, 3);   // 50
NarayanaRow(6);   // 0, 1, 15, 50, 50, 15, 1
```

**Сложность `NarayanaRow`:** O(n²) через одну `PascalRow`.

## Числа Фусса–Каталана

**Определение:** `A_n^(m) = C((m+1)·n, n) / (m·n + 1)`.

**Смысл:** (m+1)-арные деревья. При m = 1 — обычные числа Каталана, при m = 2 — тернарные деревья.

**Формула целочисленна:** деление всегда точное.

**При m = 1:** [A000108](https://oeis.org/A000108) — Каталан.

**При m = 2:** [A001764](https://oeis.org/A001764) — тернарные деревья.

**При m = 3:** [A002293](https://oeis.org/A002293) — четвертичные деревья.

```csharp
FussCatalan(5, 1);   // 42   = Catalan(5)
FussCatalan(5, 2);   // 273  — тернарные
FussCatalan(5, 3);   // 969  — четвертичные

FussCatalanSequence(8, 2);  // 1, 1, 3, 12, 55, 273, 1428, 7752
```

## Сравнение обобщений

| Обобщение | Параметр | При значении даёт Каталан |
|---|---|---|
| Нараян `N(n, k)` | число внешних пар k | при суммировании по k |
| Фусс–Каталан `A_n^(m)` | арность m+1 | m = 1 |
| Моцкин 2-цветный | 2 цвета горизонтали | сдвиг: `C_{n+1}` |

## Зачем это нужно

Нараян и Фусс–Каталан — «декомпозиции» Каталана. Нараян показывает, **как распределены** скобочные последовательности по числу внешних пар. Фусс–Каталан обобщает Каталана на деревья большей арности — это ключевое семейство для анализа алгоритмов с ветвлением.

## Как это выводится

### Числа Нараяны

Пусть `N(n, k)` — число правильных скобочных последовательностей из n пар ровно с k «внешними» парами (на верхнем уровне).

**Декомпозиция:** последовательность вида `(A)B`, где A — внутренняя последовательность, B — оставшаяся часть. Если всего k верхних пар:

- Внутренняя часть — правильная последовательность из i пар (i может быть 0..n−1).
- Оставшаяся часть — последовательность из n−1−i пар с k−1 верхними (без учёта первой пары).

Это даёт сложную рекуррентность. Замкнутая формула:

```
N(n, k) = (1/n) · C(n, k) · C(n, k−1)
```

### Числа Фусса–Каталана

Обобщение Каталана: вместо бинарных деревьев рассматриваем (m+1)-арные. Каждый узел имеет либо 0, либо (m+1) потомков.

**Рекуррентность:** `A_n^(m) = Σ_{i_1 + … + i_{m+1} = n−1} A_{i_1}^(m) · … · A_{i_{m+1}}^(m)`.

**Замкнутая формула** через обобщение формулы Каталана:

```
A_n^(m) = C((m+1)·n, n) / (m·n + 1)
```

Это целое число для всех n, m — нетривиальный факт, следует из целочисленности комбинаторного объекта.

## Где встречается

| Задача | Что использовать |
|---|---|
| Скобочные последовательности с k верхними парами | `Narayana(n, k)` |
| Пути Дика с k пиками | `Narayana(n, k)` |
| Тернарные деревья (каждый узел — 0 или 3 ребёнка) | `FussCatalan(n, 2)` |
| Четвертичные деревья | `FussCatalan(n, 3)` |
| (m+1)-арные деревья | `FussCatalan(n, m)` |
| Стеки с m-арным ветвлением | `FussCatalan` |

## Как это использовать на практике

### Разбор текста (парсеры)

Если ваш парсер использует грамматику, где каждый нетерминал может развернуться в `m+1` частей — число возможных деревьев разбора растёт как `A_n^(m)`. Это используется в оценке сложности парсеров.

### Хеш-таблицы с цепочками

Тернарные деревья (m = 2) всплывают в анализе B-деревьев и хеш-таблиц с коллизиями.

### Диаграммы Юнга

Фусс–Каталан связаны с разбиениями числа n в (m+1)-угольник, что используется в теории представлений.

## Связи

- `Σ_k N(n, k) = C_n` — сумма по всем k даёт Каталана.
- `N(n, k) = N(n, n+1−k)` — симметрия.
- `A_n^(1) = C_n` — при m = 1 обычный Каталан.
- `A_n^(2) = C(3n, n)/(2n+1)` — тернарные деревья, [OEIS A001764](https://oeis.org/A001764).

## Типичные ошибки

**1. Путать индексы в Нараяне.**

`N(n, k)` определён для `1 ≤ k ≤ n`. `N(n, 0) = 0` (нельзя иметь 0 верхних пар в правильной последовательности из n пар).

**2. Ошибиться с параметром m в Фусс–Каталане.**

- `m = 1` — бинарные деревья (обычный Каталан).
- `m = 2` — **тернарные** (3 ребёнка), не 2!
- `m = 3` — четвертичные (4 ребёнка).

Формула: `(m+1)`-арные = `m`-параметр.

**3. Считать `Narayana` через перебор.**

Формула `N(n, k) = (1/n) · C(n, k) · C(n, k−1)` даёт ответ мгновенно. Для строки — через `PascalRow`.

**4. Забыть про целочисленность деления.**

`C((m+1)n, n) / (m·n + 1)` — всегда целое, но при вычислении через BigInteger нужно делить **точно**. Наш метод `FussCatalan` гарантирует это.
