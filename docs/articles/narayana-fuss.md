# Числа Нараяны и Фусса–Каталана

Два обобщения чисел Каталана.

## Числа Нараяны

**Определение:** `N(n, k) = (1/n) · C(n, k) · C(n, k−1)`.

**Смысл:** правильные скобочные последовательности из n пар ровно с k «внешними» (верхними) парами. Эквивалентно — пути Дика длины 2n ровно с k пиками.

**Сумма по k:** `Σ_{k=1}^{n} N(n, k) = C_n` (число Каталана).

**Симметрия:** `N(n, k) = N(n, n+1−k)`.

**OEIS:** [A001263](https://oeis.org/A001263).

**Треугольник:**

| n\k | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| 1 | 1 | | | | |
| 2 | 1 | 1 | | | |
| 3 | 1 | 3 | 1 | | |
| 4 | 1 | 6 | 6 | 1 | |
| 5 | 1 | 10 | 20 | 10 | 1 |

```csharp
Narayana(4, 2);   // 6
Narayana(6, 3);   // 50
NarayanaRow(6);   // 0, 1, 15, 50, 50, 15, 1
```

**Сложность `NarayanaRow`:** O(n²) через одну `PascalRow`.

## Числа Фусса–Каталана

**Определение:** `A_n^(m) = C((m+1)·n, n) / (m·n + 1)`.

**Смысл:** (m+1)-арные деревья. При m = 1 — обычные числа Каталана, при m = 2 — тернарные деревья.

**Формула целочисленна:** деление всегда точное.

**При m = 1:** [A000108](https://oeis.org/A000108) — Каталан.

**При m = 2:** [A001764](https://oeis.org/A001764) — тернарные деревья.

**При m = 3:** [A002293](https://oeis.org/A002293) — четвертичные деревья.

```csharp
FussCatalan(5, 1);   // 42   = Catalan(5)
FussCatalan(5, 2);   // 273  — тернарные
FussCatalan(5, 3);   // 969  — четвертичные

FussCatalanSequence(8, 2);  // 1, 1, 3, 12, 55, 273, 1428, 7752
```

## Сравнение обобщений

| Обобщение | Параметр | При значении даёт Каталан |
|---|---|---|
| Нараян `N(n, k)` | число внешних пар k | при суммировании по k |
| Фусс–Каталан `A_n^(m)` | арность m+1 | m = 1 |
| Моцкин 2-цветный | 2 цвета горизонтали | сдвиг: `C_{n+1}` |
