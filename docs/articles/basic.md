# Базовые вычисления

Факториал, перестановки, размещения, сочетания, треугольник Паскаля — фундамент всей комбинаторики.

## Факториал

**Определение:** `n! = 1 · 2 · 3 · … · n`, `0! = 1`.

**Смысл:** число всех перестановок n различных элементов.

**Формула:** прямая.

**OEIS:** [A000142](https://oeis.org/A000142).

```csharp
Factorial(0);    // 1
Factorial(5);    // 120
Factorial(10);   // 3628800
Factorial(20);   // 2432902008176640000
Factorial(100);  // 9.33e157
```

**Сложность:** O(n log² n) через divide & conquer.

## Перестановки

**Определение:** `P(n) = n!`.

**Смысл:** число способов упорядочить n различных элементов.

```csharp
Permutations(5);   // 120
```

**Синоним** `Factorial`. Оставлен для семантической ясности.

## Перестановки с повторениями

**Определение:** `n! / (n₁! · n₂! · … · n_k!)`.

**Смысл:** число различных перестановок мультимножества.

**Пример:** сколько различных анаграмм у слова MISSISSIPPI (M×1, I×4, S×4, P×2)?

```csharp
PermutationsWithRepetition(1, 4, 4, 2); // 34650
```

## Размещения

**Определение:** `A(n, k) = n! / (n−k)!`.

**Смысл:** число упорядоченных выборок длины k из n элементов. В отличие от сочетаний, порядок важен.

```csharp
Arrangements(10, 3);   // 720 — сколько способов распределить 3 призовых места
Arrangements(5, 5);    // 120 = 5!
```

**OEIS:** [A008279](https://oeis.org/A008279).

## Сочетания

**Определение:** `C(n, k) = n! / (k! · (n−k)!)`.

**Смысл:** число неупорядоченных выборок k элементов из n.

**Примеры:**
- `C(52, 5) = 2 598 960` — покерные руки.
- `C(n, 0) = C(n, n) = 1`.
- Симметрия: `C(n, k) = C(n, n−k)`.

```csharp
Combinations(5, 2);       // 10
Combinations(52, 5);      // 2598960
Combinations(100, 50);    // 1.01e29
```

**OEIS:** [A007318](https://oeis.org/A007318) (треугольник Паскаля).

**Сложность:** O(min(k, n−k)).

## Сочетания с повторениями

**Определение:** `C(n+k−1, k)`.

**Смысл:** число способов разложить k неразличимых шаров по n различимым ящикам.

```csharp
CombinationsWithRepetition(3, 4);   // 15
```

**OEIS:** [A059481](https://oeis.org/A059481).

## Треугольник Паскаля

**Определение:** строка n содержит все `C(n, k)` для `k = 0..n`.

**Рекуррентность:** `C(n, k) = C(n−1, k−1) + C(n−1, k)`.

**Свойства:**
- Сумма строки = `2^n`.
- Каждый элемент — сумма двух над ним.

```csharp
var row10 = PascalRow(10);
// 1, 10, 45, 120, 210, 252, 210, 120, 45, 10, 1
```

## Связи с другими числами

- `Catalan(n) = C(2n, n) / (n+1)`.
- `StirlingSecondKind(n, k)` — обобщение сочетаний на разбиения.
- `Bell(n) = Σ_k StirlingSecondKind(n, k)`.
