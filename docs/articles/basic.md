# Базовые вычисления

Факториал, перестановки, размещения, сочетания, треугольник Паскаля — фундамент всей комбинаторики.

## Факториал

**Определение:** `n! = 1 · 2 · 3 · … · n`, `0! = 1`.

**Смысл:** число всех перестановок n различных элементов.

**Формула:** прямая.

**OEIS:** [A000142](https://oeis.org/A000142).

```csharp
Factorial(0);    // 1
Factorial(5);    // 120
Factorial(10);   // 3628800
Factorial(20);   // 2432902008176640000
Factorial(100);  // 9.33e157
```

**Сложность:** O(n log² n) через divide & conquer.

## Перестановки

**Определение:** `P(n) = n!`.

**Смысл:** число способов упорядочить n различных элементов.

```csharp
Permutations(5);   // 120
```

**Синоним** `Factorial`. Оставлен для семантической ясности.

## Перестановки с повторениями

**Определение:** `n! / (n₁! · n₂! · … · n_k!)`.

**Смысл:** число различных перестановок мультимножества.

**Пример:** сколько различных анаграмм у слова MISSISSIPPI (M×1, I×4, S×4, P×2)?

```csharp
PermutationsWithRepetition(1, 4, 4, 2); // 34650
```

## Размещения

**Определение:** `A(n, k) = n! / (n−k)!`.

**Смысл:** число упорядоченных выборок длины k из n элементов. В отличие от сочетаний, порядок важен.

```csharp
Arrangements(10, 3);   // 720 — сколько способов распределить 3 призовых места
Arrangements(5, 5);    // 120 = 5!
```

**OEIS:** [A008279](https://oeis.org/A008279).

## Сочетания

**Определение:** `C(n, k) = n! / (k! · (n−k)!)`.

**Смысл:** число неупорядоченных выборок k элементов из n.

**Примеры:**
- `C(52, 5) = 2 598 960` — покерные руки.
- `C(n, 0) = C(n, n) = 1`.
- Симметрия: `C(n, k) = C(n, n−k)`.

```csharp
Combinations(5, 2);       // 10
Combinations(52, 5);      // 2598960
Combinations(100, 50);    // 1.01e29
```

**OEIS:** [A007318](https://oeis.org/A007318) (треугольник Паскаля).

**Сложность:** O(min(k, n−k)).

## Сочетания с повторениями

**Определение:** `C(n+k−1, k)`.

**Смысл:** число способов разложить k неразличимых шаров по n различимым ящикам.

```csharp
CombinationsWithRepetition(3, 4);   // 15
```

**OEIS:** [A059481](https://oeis.org/A059481).

## Треугольник Паскаля

**Определение:** строка n содержит все `C(n, k)` для `k = 0..n`.

**Рекуррентность:** `C(n, k) = C(n−1, k−1) + C(n−1, k)`.

**Свойства:**
- Сумма строки = `2^n`.
- Каждый элемент — сумма двух над ним.

```csharp
var row10 = PascalRow(10);
// 1, 10, 45, 120, 210, 252, 210, 120, 45, 10, 1
```

## Связи с другими числами

- `Catalan(n) = C(2n, n) / (n+1)`.
- `StirlingSecondKind(n, k)` — обобщение сочетаний на разбиения.
- `Bell(n) = Σ_k StirlingSecondKind(n, k)`.

## Зачем это нужно

Базовые операции — фундамент, на котором строятся все остальные семейства. Каждое следующее число (Каталан, Стирлинг, Белл и т.д.) — это либо модификация сочетаний, либо их сумма с ограничениями. Без `Combinations` и `Factorial` не вывести ни одну формулу.

## Как это выводится

### Факториал

`n!` — это просто произведение `1 · 2 · … · n`. Возникает естественным образом, потому что первое место можно занять n способами, второе — (n−1) способами, и т.д. Отсюда `n · (n−1) · … · 1 = n!` — число перестановок.

### Сочетания

Почему `C(n, k) = n! / (k! · (n−k)!)`?

1. Всего размещений длины k из n: `A(n, k) = n! / (n−k)!`.
2. Каждое сочетание соответствует `k!` различным размещениям (перестановка выбранных k элементов).
3. Поэтому `C(n, k) = A(n, k) / k! = n! / (k! · (n−k)!)`.

### Формула Паскаля

Почему `C(n, k) = C(n−1, k−1) + C(n−1, k)`?

Рассмотрим элемент `a_1`. Любое подмножество размера k либо содержит `a_1` (тогда оставшиеся k−1 выбираются из n−1), либо не содержит (тогда все k выбираются из n−1). Это даёт два слагаемых.

## Где встречается

| Задача | Что использовать |
|---|---|
| Раздать k призовых мест из n участников | `Arrangements(n, k)` — порядок важен |
| Выбрать k человек в комитет из n | `Combinations(n, k)` — порядок не важен |
| Анаграммы слова с повторяющимися буквами | `PermutationsWithRepetition` |
| Разложить k шаров по n ящикам (шары неразличимы) | `CombinationsWithRepetition(n, k)` |
| Найти коэффициент `x^k` в `(1+x)^n` | `Combinations(n, k)` |
| Посчитать все подмножества множества | `Σ_k C(n, k) = 2^n` |

## Типичные ошибки

**1. Путать сочетания и размещения.**

- «Выбрать 3 из 10 для команды» — это сочетания (`C(10, 3) = 120`).
- «Выбрать 3 из 10 для призовых мест» — это размещения (`A(10, 3) = 720`).

Порядок важен или нет — главный вопрос.

**2. Забыть про случай `k = 0`.**

`C(n, 0) = 1` всегда, даже для `n = 0`: `C(0, 0) = 1`. Пустое множество — тоже подмножество.

**3. Считать `n!` в цикле как `int`.**

`13! = 6 227 020 800 > int.MaxValue`. Всегда `BigInteger`.

**4. Использовать `Combinations(n, k)` в цикле для построения строки Паскаля.**

Это O(n² · k) вместо O(n²). Строку строят через `PascalRow(n)` — там `C(n, k) = C(n−1, k−1) + C(n−1, k)`.
