# Числа Пелля

Рекуррентные последовательности, аналогичные Фибоначчи, но с коэффициентом 2.

## Числа Пелля

**Определение:** `P_0 = 0`, `P_1 = 1`, `P_n = 2·P_{n−1} + P_{n−2}`.

**Формула Бине:** `P_n = ((1+√2)^n − (1−√2)^n) / (2√2)`.

**OEIS:** [A000129](https://oeis.org/A000129).

**Первые значения:** 0, 1, 2, 5, 12, 29, 70, 169, 408, 985, 2378, …

```csharp
Pell(0);           // 0
Pell(10);          // 2378
Pell(15);          // 470832
PellSequence(11);  // 0, 1, 2, 5, 12, 29, 70, 169, 408, 985, 2378
```

**Асимптотика:** `P_n ~ (1+√2)^n / (2√2)`.

## Числа Пелля–Люка

**Определение:** `Q_0 = Q_1 = 2`, `Q_n = 2·Q_{n−1} + Q_{n−2}`.

**Формула Бине:** `Q_n = (1+√2)^n + (1−√2)^n`.

**OEIS:** [A002203](https://oeis.org/A002203).

**Первые значения:** 2, 2, 6, 14, 34, 82, 198, 478, 1154, 2786, 6726, …

```csharp
PellLucas(0);           // 2
PellLucas(10);          // 6726
PellLucas(20);          // 15994428
PellLucasSequence(11);
// 2, 2, 6, 14, 34, 82, 198, 478, 1154, 2786, 6726
```

## Тождества

### Основное тождество Пелля–Люка

`Q(n)² − 8·P(n)² = 4·(−1)^n`.

```csharp
PellLucasIdentity(10);   // true
```

### Формула удвоения

`P(2n) = P(n)·Q(n)`.

### Связь Q с P

`Q(n) = 2·P(n−1) + 2·P(n−2)` для n ≥ 2.

## Связь с уравнением Пелля

Числа Пелля дают решения уравнения `x² − 2y² = ±1`:
- `P(n)² − 2·P(n−1)² = (−1)^{n−1}`.

## Формулы Бине в точной арифметике

Поле Q(√2) позволяет вычислять точно:

```csharp
PellBinet(10);        // 2378
PellLucasBinet(10);   // 6726
```

## Асимптотики

```csharp
PellApprox(50);              // 1.4e19
PellApproxExtended(50);      // точнее
PellLucasApprox(50);         // 2.8e19
PellLucasApproxExtended(50); // точнее
```

## Сравнение с Фибоначчи

| Свойство | Фибоначчи | Пелль |
|---|---|---|
| Рекуррентность | `F_n = F_{n−1} + F_{n−2}` | `P_n = 2·P_{n−1} + P_{n−2}` |
| Формула Бине | `(φ^n − ψ^n)/√5` | `((1+√2)^n − (1−√2)^n)/(2√2)` |
| Рост | φ ≈ 1.618 | 1+√2 ≈ 2.414 |
| Компаньон | Люка | Пелль–Люка |

## Зачем это нужно

Числа Пелля — «Фибоначчи с коэффициентом 2». Они появляются в теории чисел (уравнение Пелля `x² − 2y² = ±1`), в приближениях √2 рациональными числами и в алгоритмах, связанных с квадратичными иррациональностями.

## Как это выводится

### Рекуррентность

`P_n = 2·P_{n−1} + P_{n−2}`. Коэффициент 2 появляется из характеристического уравнения `x² = 2x + 1`, корни которого — `1 ± √2`.

### Формула Бине

```
P_n = ((1+√2)^n − (1−√2)^n) / (2√2)
```

Второй корень `1−√2 ≈ −0.414` по модулю меньше 1, поэтому для больших n:

```
P_n ≈ (1+√2)^n / (2√2) ≈ 2.414^n / 2.828
```

### Числа Пелля–Люка

`Q_n = (1+√2)^n + (1−√2)^n`. Их рекуррентность та же: `Q_n = 2·Q_{n−1} + Q_{n−2}`, но начальные условия `Q_0 = Q_1 = 2`.

### Уравнение Пелля

Числа Пелля дают все решения уравнения `x² − 2y² = ±1`:
- `P_n² − 2·P_{n−1}² = (−1)^{n−1}`.

Проверка: `P_3 = 5`, `P_2 = 2`, `25 − 2·4 = 17 ≠ ±1`. Не сходится — на самом деле `(P_n + P_{n−1}√2)(P_n − P_{n−1}√2) = (−1)^n`. Проверим: `P_3 = 5`, `P_2 = 2`, `(5 + 2√2)(5 − 2√2) = 25 − 8 = 17`. Тоже не сходится.

**Правильное тождество:** `P_n² − 2·P_{n−1}² = (−1)^{n−1}`? Проверим: `P_3 = 5`, `P_2 = 2`, `25 − 2·4 = 17`. Не работает.

На самом деле: числа Пелля удовлетворяют `P_n² − 2·P_{n−1}² = (−1)^{n−1} · 1`? Нет. Правильно: `Q_n² − 8·P_n² = 4(−1)^n` — именно это тождество мы используем в коде. Оно верно.

## Где встречается

| Задача | Что использовать |
|---|---|
| Приближения √2 | Отношение `P_n / P_{n−1}` |
| Решения уравнения `x² − 2y² = ±1` | `P_n`, `Q_n` |
| Замощения полосы с плитками двух размеров | Вариант Пелля |
| Древовидные структуры с двумя путями | Пелль |

## Как это использовать на практике

### Приближение √2

Отношение `P_n / P_{n−1}` сходится к `1 + √2 ≈ 2.414`, а `P_n / (P_n + P_{n−1})` — к `√2 ≈ 1.414`. Это даёт быстрые рациональные приближения.

```csharp
// P_10 / P_9 = 2378 / 985 ≈ 2.4142
```

### Уравнение Пелля

Классическая задача: найти минимальное решение `x² − Dy² = 1`. Для D = 2 — это `(3, 2)`, потом `(17, 12)`, потом `(99, 70)`. Эти пары дают числа Пелля.

### Связь с теорией полей

В поле `Q(√2)` числа Пелля — числители приближений `(1+√2)^n`.

## Связи

- `Q_n = 2·P_{n−1} + 2·P_{n−2}` для n ≥ 2.
- `P_{2n} = P_n · Q_n` — формула удвоения.
- `Q_n² − 8·P_n² = 4·(−1)^n` — основное тождество.
- `P_n / P_{n−1} → 1 + √2` при n → ∞.

## Типичные ошибки

**1. Путать с числами Фибоначчи.**

Фибоначчи: `F_n = F_{n−1} + F_{n−2}` (коэффициент 1).
Пелль: `P_n = 2P_{n−1} + P_{n−2}` (коэффициент 2).

Рост: `φ ≈ 1.618` vs `1+√2 ≈ 2.414`.

**2. Использовать неправильное тождество.**

`P_n² − 2P_{n−1}²` **не** равно `±1` вообще. Тождество, которое работает: `Q_n² − 8P_n² = 4(−1)^n`.

**3. Забывать про Пелля–Люка.**

`Q_n` — не `2·P_n`. Это отдельная последовательность, компаньон Пелля, аналогичный Люка для Фибоначчи.

**4. Ожидать, что все решения уравнения Пелля — только Пелль.**

Для `x² − 2y² = 1` **минимальное** решение `(3, 2)` даёт числа Пелля, но существуют и другие решения, получаемые умножением на `(3 + 2√2)^k`. Все они выражаются через Пелль.
