# Пути: Деланнуа и Шрёдер

Числа, считающие пути на решётке с диагональными шагами.

## Числа Деланнуа

**Определение:** `D(m, n)` — число путей из (0,0) в (m, n) с шагами (1,0), (0,1), (1,1).

**Формула:** `D(m, n) = Σ_{k=0}^{min(m,n)} C(m, k) · C(n, k) · 2^k`.

**Рекуррентность:** `D(m,n) = D(m−1,n) + D(m,n−1) + D(m−1,n−1)`, `D(0,0) = 1`.

**Симметрия:** `D(m, n) = D(n, m)`.

**OEIS:** [A008288](https://oeis.org/A008288).

```csharp
Delannoy(1, 1);   // 3
Delannoy(3, 3);   // 63
Delannoy(5, 5);   // 1683
Delannoy(2, 3);   // 25
```

## Центральные числа Деланнуа

**Определение:** `D(n, n)` — пути из угла в угол квадрата.

**OEIS:** [A001850](https://oeis.org/A001850).

**Первые значения:** 1, 3, 13, 63, 321, 1683, 8989, 48639, …

```csharp
DelannoyCentral(5);   // 1683
DelannoyCentralSequence(8);
// 1, 3, 13, 63, 321, 1683, 8989, 48639
```

**Асимптотика:** `D(n, n) ~ (3+2√2)^n / (2^{3/4} · √(πn))`.

**Автовыбор метода:** для `m·n > 2500` используется рекуррентность (быстрее), иначе — закрытая формула.

## Большие числа Шрёдера

**Определение:** `S_n` — число путей из (0,0) в (n,n) с шагами (1,0), (0,1), (1,1), **не поднимающихся выше диагонали** y = x.

**Формула:** `S_n = Σ_{k=0}^{n} C(n+k, n−k) · C_k`.

**Рекуррентность:** `(n+2)·S_{n+1} = 3(2n+1)·S_n − (n−1)·S_{n−1}`.

**OEIS:** [A006318](https://oeis.org/A006318).

**Первые значения:** 1, 2, 6, 22, 90, 394, 1806, 8558, 41586, …

```csharp
SchroederLarge(0);   // 1
SchroederLarge(5);   // 394
SchroederLarge(8);   // 41586

SchroederLargeSequence(9);
// 1, 2, 6, 22, 90, 394, 1806, 8558, 41586
```

**Сложность:** O(n) через рекуррентность.

## Малые числа Шрёдера

**Определение:** `s_n` — то же, но без шагов вдоль диагонали.

**Связь с большими:** `s_n = S_n / 2` для n ≥ 1; `s_0 = 1`.

**OEIS:** [A001003](https://oeis.org/A001003).

**Первые значения:** 1, 1, 3, 11, 45, 197, 903, 4279, …

```csharp
SchroederSmall(0);   // 1
SchroederSmall(5);   // 197
SchroederSmall(8);   // 20793
```

## Числа Шрёдера–Каталана

**Синоним малых чисел Шрёдера** в русскоязычной литературе.

```csharp
SchroederCatalan(7);   // 4279
```

## Асимптотики

```csharp
DelannoyCentralApprox(100);           // ~1.5e76
DelannoyCentralApproxExtended(100);   // точнее
SchroederLargeApprox(100);            // ~1.5e76
SchroederLargeApproxExtended(100);    // точнее
```
