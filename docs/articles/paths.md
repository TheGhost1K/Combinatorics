# Пути: Деланнуа и Шрёдер

Числа, считающие пути на решётке с диагональными шагами.

## Числа Деланнуа

**Определение:** `D(m, n)` — число путей из (0,0) в (m, n) с шагами (1,0), (0,1), (1,1).

**Формула:** `D(m, n) = Σ_{k=0}^{min(m,n)} C(m, k) · C(n, k) · 2^k`.

**Рекуррентность:** `D(m,n) = D(m−1,n) + D(m,n−1) + D(m−1,n−1)`, `D(0,0) = 1`.

**Симметрия:** `D(m, n) = D(n, m)`.

**OEIS:** [A008288](https://oeis.org/A008288).

```csharp
Delannoy(1, 1);   // 3
Delannoy(3, 3);   // 63
Delannoy(5, 5);   // 1683
Delannoy(2, 3);   // 25
```

## Центральные числа Деланнуа

**Определение:** `D(n, n)` — пути из угла в угол квадрата.

**OEIS:** [A001850](https://oeis.org/A001850).

**Первые значения:** 1, 3, 13, 63, 321, 1683, 8989, 48639, …

```csharp
DelannoyCentral(5);   // 1683
DelannoyCentralSequence(8);
// 1, 3, 13, 63, 321, 1683, 8989, 48639
```

**Асимптотика:** `D(n, n) ~ (3+2√2)^n / (2^{3/4} · √(πn))`.

**Автовыбор метода:** для `m·n > 2500` используется рекуррентность (быстрее), иначе — закрытая формула.

## Большие числа Шрёдера

**Определение:** `S_n` — число путей из (0,0) в (n,n) с шагами (1,0), (0,1), (1,1), **не поднимающихся выше диагонали** y = x.

**Формула:** `S_n = Σ_{k=0}^{n} C(n+k, n−k) · C_k`.

**Рекуррентность:** `(n+2)·S_{n+1} = 3(2n+1)·S_n − (n−1)·S_{n−1}`.

**OEIS:** [A006318](https://oeis.org/A006318).

**Первые значения:** 1, 2, 6, 22, 90, 394, 1806, 8558, 41586, …

```csharp
SchroederLarge(0);   // 1
SchroederLarge(5);   // 394
SchroederLarge(8);   // 41586

SchroederLargeSequence(9);
// 1, 2, 6, 22, 90, 394, 1806, 8558, 41586
```

**Сложность:** O(n) через рекуррентность.

## Малые числа Шрёдера

**Определение:** `s_n` — то же, но без шагов вдоль диагонали.

**Связь с большими:** `s_n = S_n / 2` для n ≥ 1; `s_0 = 1`.

**OEIS:** [A001003](https://oeis.org/A001003).

**Первые значения:** 1, 1, 3, 11, 45, 197, 903, 4279, …

```csharp
SchroederSmall(0);   // 1
SchroederSmall(5);   // 197
SchroederSmall(8);   // 20793
```

## Числа Шрёдера–Каталана

**Синоним малых чисел Шрёдера** в русскоязычной литературе.

```csharp
SchroederCatalan(7);   // 4279
```

## Асимптотики

```csharp
DelannoyCentralApprox(100);           // ~1.5e76
DelannoyCentralApproxExtended(100);   // точнее
SchroederLargeApprox(100);            // ~1.5e76
SchroederLargeApproxExtended(100);    // точнее
```

## Зачем это нужно

Деланнуа и Шрёдер — счётчики **путей с диагональными шагами**. Это обобщения Каталана и Моцкина, где разрешены движения по диагонали. Они появляются в анализе алгоритмов на решётках, в физике (случайные блуждания) и в биоинформатике (выравнивание последовательностей).

## Как это выводится

### Числа Деланнуа

Рассмотрим пути из (0,0) в (m, n) с шагами `→`, `↑`, `↗`. Каждый путь имеет:
- `a` горизонтальных шагов,
- `b` вертикальных,
- `c` диагональных,

с условиями `a + c = m`, `b + c = n`. Отсюда `c = k` — число диагональных, `a = m − k`, `b = n − k`.

Число способов расположить эти шаги: `(m + n − k)! / (a! · b! · c!)`.

Суммируя по k от 0 до min(m, n), получаем:

```
D(m, n) = Σ_{k=0}^{min(m,n)} C(m, k) · C(n, k) · 2^k
```

Множитель `2^k` — потому что каждый диагональный шаг можно заменить парой `→↑` (или `↑→`), что даёт 2 варианта на каждый диагональный.

### Большие Шрёдера

Пути из (0,0) в (n, n), не поднимающиеся выше диагонали y = x, с шагами `→`, `↑`, `↗`.

**Декомпозиция:** разобьём путь по первому касанию диагонали. Получаем рекуррентность:

```
S_n = S_{n−1} + Σ_{k=0}^{n−1} S_k · S_{n−1−k}
```

Через числа Каталана: `S_n = Σ_k C(n+k, n−k) · C_k`.

### Малые Шрёдера

Отличаются тем, что диагональные шаги `↗` запрещены (только `→` и `↑`). Связь:

```
s_n = S_n / 2   для n ≥ 1
s_0 = S_0 = 1
```

## Где встречается

| Задача | Что использовать |
|---|---|
| Пути на решётке с диагоналями | `Delannoy(m, n)` |
| Центральные (из угла в угол квадрата) | `DelannoyCentral(n)` |
| Пути без подъёма выше диагонали | `SchroederLarge(n)` |
| Унимодальные пути | `SchroederSmall(n)` |
| Диссекции прямоугольников | Шрёдер |

## Как это использовать на практике

### Выравнивание последовательностей (биоинформатика)

Классический алгоритм Нидлмана–Вунша для выравнивания ДНК-последовательностей основан на динамическом программировании, где на каждом шаге три операции: вставка, удаление, замена. Это в точности структура путей Деланнуа.

### Случайные блуждания

Деланнуа считает траектории частицы, движущейся по решётке с шагами `→`, `↑`, `↗`. Используется в физике полимеров.

### Компиляторы

Шрёдер появляется в анализе деревьев разбора для грамматик с правой рекурсией.

### Асимптотика

Обе последовательности растут как `(3+2√2)^n ≈ 5.828^n`. Это медленнее, чем `4^n` для Каталана, но быстрее, чем `2^n`.

## Связи

- `SchroederLarge(n) / 2 = SchroederSmall(n)` для n ≥ 1.
- `SchroederLarge(n) ≥ Catalan(n)` для n ≥ 1.
- `Delannoy(1, 1) = 3` = число путей из (0,0) в (1,1).
- `Delannoy(n, n)` растёт как `(3+2√2)^n / (2^{3/4}√(πn))`.

## Типичные ошибки

**1. Путать большие и малые Шрёдера.**

- **Большие** `S_n`: 1, 2, 6, 22, 90, …
- **Малые** `s_n`: 1, 1, 3, 11, 45, …

Разница в 2 раза для n ≥ 1.

**2. Считать `Delannoy(m, n)` через формулу для больших m, n.**

Формула `Σ_k C(m, k) · C(n, k) · 2^k` — O(min(m, n)) вызовов `Combinations`, каждый O(k). Итого O(min(m,n)²). Для больших значений рекуррентная реализация быстрее. Наш `Delannoy` выбирает автоматически при `m·n > 2500`.

**3. Ожидать, что Шрёдер = Каталан.**

Нет. Шрёдер считает **все** пути без подъёма выше диагонали, включая диагональные шаги. Каталан — только горизонтальные и вертикальные. `S_3 = 22 > C_3 = 5`.

**4. Забыть про симметрию Деланнуа.**

`D(m, n) = D(n, m)` — количество путей из угла в угол прямоугольника m × n не зависит от ориентации. Используйте это для упрощения вычислений.
